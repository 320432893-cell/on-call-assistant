## 0. 一句话讲清这个项目

> 我们做了一个**上市公司市值的"解释性分析"**:对移为通信 + 13 家同赛道公司,用会计恒等把市值变动拆成**经营(营收)通道 + 估值(再定价)通道**,再用可解释 ML + **wild cluster bootstrap 三角验证**找出"什么真正驱动估值差异"、哪些是算术假象,并诚实量化"有多少根本解释不了(情绪)"。**不预测股价,是解释市值为什么这样。**

**为什么这么定题(务必能答)**:① 预测股价在近有效市场做不到(旧预测线 IC~0.14、已弃);② CFO 真正要的是"市值由什么构成、差在哪、补哪项最划算",这是**解释**问题;③ 直接看"谁市值高就学谁"会被混淆和算术假象骗,所以必须**剥掉机械成分 + 多方法验证**才知道哪条是真规律。

## 2. 诚实的故事线(项目的灵魂)

1. **算账**:市值变动 56% 是估值再定价、44% 经营;移为 ×1.3 = 营收 ×2.46 × 倍数 ×0.53(增收没躲过估值压缩)。
2. **找驱动**:用 ML+SHAP 看什么驱动估值——但 SHAP 会把"算术巧合"(毛利率含营收)照得发亮,所以**只作粗筛**。
3. **验真伪**:每条假设过 5 类方法。**成长被打折 5/5、低杠杆↔高估值 5/5(关联)** 立住;**盈利率驱动估值 1/5 被证伪**(剥掉与营收的算术相关就塌)。
4. **不糊弄**:主动删伪规律(成功公式/盈利驱动);污染防火墙逐特征标记;黑盒给白盒证明。
5. **认天花板**:估值约一半是情绪/叙事,任何数据补不上——诚实量化而非假装能解释。

## 3. 关键数字(背下来)

- 样本:14 家、483 行、2009–2026;经营 44%/估值 56%。
- **成长打折 β=0.58**(<1,CI 0.36–0.79);**低杠杆↔高估值 β=−0.52**;盈利率证伪。
- 估值模型 OOT 0.49 / LOFO 0.50;**不可解释 ~50%**。
- 移为:纯出口海外 97% 但海外增速仅 +6%(赢家 +50~69%);PS 溢价 +0.70 靠低负债;**低负债已最优,市值靠营收成长(做到赢家档→约 ×3.0)**。
- 白盒证明:线性 OOT 0.454 vs GBT 0.49,黑盒只多 3.6%。

## 4. 两套口径

- **课程展示**:卖点 = 方法严谨 + 诚实。"我们没糊弄——每条结论都能用一行公式手算、过 5 种方法验证、明确标了哪些是情绪不可约、还主动删掉了看着漂亮的伪规律。"
- **CFO 汇报**:卖点 = 可操作 + 边界清楚。"移为市值卡在营收增速跑不赢同行 + 全行业估值压缩;你的资产表(低负债)已经最优,估值上没空间了;**唯一可靠引擎是把营收尤其海外做起来**;别信'改善盈利率抬估值'(已证是假象)。"

## 5. 问答预案(高频追问)

- **Q:这是因果吗?** A:不是,是稳健关联。便宜的准因果(公司内固定效应+领先滞后+安慰剂)已做;但 N=14、无外生冲击,正式 IV/DiD 会是噪声,所以不声称因果——这比一个弱 IV 更诚实。
- **Q:就 14 家,样本太小?** A:对,这是真瓶颈;所以我们用对少簇的推断(wild cluster bootstrap)、诚实标了 ~50% 天花板、对次新股加 caveat,不在小样本上硬下结论。
- **Q:用了 ML 是不是黑盒?** A:硬结论是线性系数、能手算;白盒证明 GBT 在样本外只多解释 3.6%,只作佐证。
- **Q:为什么不预测股价?** A:近有效市场预测不了(旧线 IC~0.14 已弃);过拟合是结构性的;我们做的是解释,预测只当诚实的建议层。
- **Q:盈利能力难道不重要?** A:重要,但"高盈利率→高估值"剥掉算术相关后证伪了——市场为干净资产表(低杠杆)和真营收成长付费,不为盈利率包装。

## 6. 别踩的坑

- 别说"找到了抬市值的公式"——经不起追问;说"找到了哪些是真规律、哪些是假象、哪些是情绪"。
- 别讲任何旧线(预测 IC、机构关注、资本动作 20 日反应)。
- 别把 SHAP 排名当结论(它把污染特征排高);最终裁决是 WCB 三角。
