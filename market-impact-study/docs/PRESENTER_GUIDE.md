# 汇报人手册：全流程、做了什么、达到什么效果、要补的知识

> 给自己汇报用（课程展示 + CFO 汇报两套口径）。2026-06-15。配合 `reports/V3_MODEL_AND_INTERPRETABILITY_SUMMARY.md`、`PRESENTATION_RESULTS_SUMMARY.md`、`ACCURACY_AND_EVALUATION_GUIDANCE.md` 一起看。

## 0. 一句话讲清这个项目

> 我们做了一个**上市公司事件级"市值反应解释系统"**：对移为通信及 8 家同行，把每一次公告/业绩/调研等事件，转成"事件后 20 天相对同行的市值反应"，用机器学习去**复现和解释**这个反应由什么驱动，并诚实地界定能解释多少、剩下是噪声。**不是预测股价，是解释市值反应、并转成 CFO 的披露/投关/风险沟通建议。**

为什么这么定题（务必能答）：直接预测绝对股价是近有效市场里几乎做不到的事；改成"**相对同行**"反应，等于先把行业一起涨跌（共振）这块控制掉，剩下的才是公司自己的部分——这让问题有金融逻辑、也更可控。

## 2. 诚实的故事线（这是项目的灵魂，一定要这样讲）

1. **第一版几乎失败**：只用严格过滤后的 300 条主样本，结果"预测全局均值"的笨基线就赢了所有模型，test IC=0、R² 为负——当前特征对相对反应没有样本外解释力。
2. **诊断而非硬堆模型**：发现两个问题——样本被砍到只剩 8%（重叠污染样本被丢了），以及特征用的是绝对量（不同体量公司不可比）。
3. **两个杠杆**：① 用全样本（带"重叠强度"作特征）n 从 300→3905；② 把每个特征换成**行业内相对表示**（同行截面秩）。→ test IC 0.000→0.193。
4. **上强模型**：LightGBM + 早停 + 正则 → test IC 0.216、**R² 转正**、原来失效的 2024 也修好了。
5. **三方交叉验证解释**：SHAP、置换重要性、稳健回归一致指向——**相对规模、相对流动性、异常机构关注**是驱动；严格统计推断下只有"相对规模"无争议显著。
6. **诚实证否两个假设**：业绩预期差、大波动幅度——都试了、都没用（大波动 AUC≈0.50），并解释了机理。这反而是"评估科学性"的加分项。

一句话收尾：**"在近有效市场里，我们诚实地分离了信号与噪声：能解释的是一组已知风险因子（小市值/低流动性/高关注），它稳定但弱；我们没有假装预测得准，而是证明了什么经得起检验。"**

## 3. 核心结果速查（背下来）

- 主指标 **test Spearman IC 0.216**（v4 LightGBM），R² +0.027，9 家公司全为正。
- **分位 lift**：模型排名前 1/5 事件 事件后相对市值 **+3.5%**，后 1/5 **−4.6%**，**首尾差 ~8 个百分点**，单调，正向占比 25%→54%。
- **风险预警**：标为最高危的十分位，**78% 真的下跌**；负向冲击 recall 0.53、PR-AUC 0.59（基线 0.49）。
- **高置信方向准确率 65%**（只判最有把握的 30% 事件）；裸整体方向准确率 0.54 < 基线 0.60（所以不报裸准确率）。
- **稳健推断**：相对规模系数 WCB p<0.001；流动性/波动/关注边际显著（p≈0.06–0.09）。
- **诚实 null**：surprise 特征加进去 IC 0.216→0.220（无效）；大波动检测 AUC≈0.50（不可预测）。

## 4. 必须搞懂的知识点（"补知识"清单，按重要性）

每条给"是什么 + 在本项目里为什么重要"，深入再各自查资料。

**A. 金融/计量核心**
1. **事件研究法（event study）**：围绕事件日开一个窗口看异常反应。本项目窗口 = 事件后 0~20 个交易日。
2. **异常收益 / 相对收益**：公司收益 − 基准。本项目基准 = 剔除自身的 8 家同行等权平均 → 控制"行业一起涨跌"。要能解释为什么用同行而不是大盘指数（同行更贴近、控制行业共振）。
3. **有效市场假说（EMH）**：价格已反映公开信息，所以"事件后还能不能预测"本身就难——这解释了为什么 IC 只有 0.2、为什么这是诚实的好结果而非失败。
4. **CAR（累计异常收益）**：本项目作辅助验证口径（30/30 抽样复算）。
5. **固定效应回归**：控制公司长期差异（公司 FE）和年份环境（年份 FE），看事件信号的净效应。
6. **聚类稳健标准误 + Wild Cluster Bootstrap**：只有 9 家公司（聚类数少），普通标准误不可靠，用 WCB（给每个公司簇随机 ±1 权重重抽上千次）算更稳的 p 值。这是把"ML 相关"升级成"统计上稳健的关联"的关键，也是和因果的分界。

**B. 机器学习/数据**
7. **数据泄漏 / 未来信息 / point-in-time**：特征的可用日期不能晚于事件日（`as_of_date ≤ event_date`）。否则"作弊"。本项目有黑名单 + 校验。
8. **时间切分 vs 随机交叉验证**：金融时序必须按时间切（训练≤2022/验证2023/测试≥2024），不能随机打乱，否则用未来预测过去。
9. **特征归一化三招**：比率（消体量，如负债/资产）、同比变化（消自身水平）、**行业内截面秩/z-score（让大小公司可比）**——这是"一个模型通吃异质公司"的核心，要能讲清楚。
10. **已知风险因子/异常**：小市值效应、低流动性溢价、反转、关注度。本项目找到的信号正是这些——既是卖点也要承认它们是"已知 beta"，所以用固定效应去控制。
11. **梯度提升树（LightGBM/XGBoost）+ 早停 + 正则**：主模型。要懂"训练集 R²0.6 但测试为负 = 过拟合"，以及早停/正则怎么治。
12. **评估指标全家桶**：MAE/RMSE/R²（回归）、**Spearman IC（排序相关，本项目主指标）**、ROC-AUC、PR-AUC、precision/recall/F1、方向准确率、**分位 lift**、校准。重点能讲**为什么在类不平衡下不用裸准确率、而用 AUC/IC/lift**。
13. **多数类基线**：正例只占 40%，无脑全猜"跌"就有 60% 准确率——所以裸准确率 0.54 反而"不如瞎猜"。这是必懂的陷阱。
14. **SHAP（Shapley 值）+ 置换重要性**：解释每个特征对预测的贡献；两者方向一致才写进主结论（三角验证）。
15. **消融实验**：逐组特征加入看 test 指标增量，证明特征工程有价值，不是堆出来的。
16. **null result 的价值**：把"试了 surprise/大波动、没用、并解释为什么"讲出来 = 科学严谨，比假装成功强。

## 5. 课程汇报口径（25–30min，对应评分 100 分）

PPT 结构建议（评分项写在括号）：
1. 选题与商业价值：为什么是"市值反应解释"而非股价预测（选题 20%）。
2. 数据与 SSOT、point-in-time 防泄漏（模型质量 40%）。
3. 标签设计：相对同行反应 + 交易日对齐（模型质量）。
4. 特征工程：财务理论依据 + 行业内相对归一化（模型质量，鲁布里克明确要"结合财务理论说明合理性"）。
5. 模型与**诚实故事线**：v2 失败→诊断→v3/v4 突破（模型质量）。
6. **多指标评估 + 为何不报裸准确率 + 两个 null 对照**（模型质量"评估科学性"——本项目最强项）。
7. 解释：SHAP/置换/WCB 三方一致 + 逐事件 waterfall（结果解释 20%）。
8. 移为通信案例 + CFO 建议（结果解释 20%）。
9. 局限与边界（加分）。

**问答预案**：
- "准确率多少？"→ 见 §3，主动讲多指标 + 多数类陷阱。
- "为什么 R²/准确率不高？"→ 近有效市场相对反应的本质，价值在排序+可解释+防泄漏；我证明了什么经得起检验。
- "怎么防止过拟合/泄漏？"→ point-in-time 校验、时间外测试、早停正则、去重/去极端值/分年分公司稳健检查。
- "这是因果吗？"→ 不是；ML 给相关，固定效应+WCB 给稳健关联，我明确不声称因果。

## 6. CFO 汇报口径（业务语言，少术语）

CFO 关心市值管理能做什么。把模型结论翻成动作：

- **结论 1**：事件前**机构关注度异常升高**的公司/事件，事件后相对市值更强 → **建议**：重大事件前主动安排机构调研/路演，把关注度做上去。
- **结论 2**：模型能把事件按"事件后相对反应"**稳定排序**（首尾差 8pp）；标为高危的事件 **78% 确实跑输** → **建议**：把模型当**事件风险预警初筛**，对高危事件提前准备投关话术和风险沟通。
- **结论 3**：相对规模/估值/流动性是主驱动（已知市场结构），公司可控的增量主要在**信息披露节奏与投关强度**。
- **诚实边界**（对 CFO 也要说）：这是**相对排序与解释工具，不是择时/股价预测**；信号弱、周期平均成立、个别年份失效；建议作为辅助判断而非自动决策。

一句话给 CFO：**"这套系统帮你回答'哪些事件、什么披露方式更可能赢得市场认可'，并给每个事件一个风险排序——它不预测股价，但能让披露和投关更有的放矢。"**
