# 因果扩展计划：事件研究的因果版（机构关注 → 相对市值反应）

> 2026-06-15。把现有"相对反应排序/解释"(预测/相关) 升级成一个**因果**子项目,复用现有 80% 数据与管道,只换"识别策略 + 反事实 + 安慰剂"这层。一点一点做,每步独立可验收。配合 `PRESENTER_GUIDE.md`、`reports/V3_MODEL_AND_INTERPRETABILITY_SUMMARY.md`。

## 0. 一句话目标 + 因果问题

> 现有项目回答"哪些事件相对反应更强"(相关);本扩展回答:**事件前的"异常机构关注"(相对公司自身基线) 是否_因果性地_提升了事件后的相对市值反应?**

为什么选它:① 是我们最强、最稳定的信号(`mgmt_institution_count__selfz`);② **CFO 可控**(IR 能主动安排调研/路演);③ 直接复用现有面板/标签/稳健推断代码。

核心张力(也是因果的全部难点):**关注不是随机分配的**——好公司天然又被多关注、又反应好(选择偏误/混淆)。所以"相关"不等于"调研真的有用"。本项目就是想办法把这个混淆扒掉。

## 1. 识别策略 + 假设（核心知识点，要能讲）

逐层加,看系数怎么动(这本身是最好的诊断):

| 步 | 做什么 | 控掉什么混淆 | 要懂的概念 |
|---|---|---|---|
| 朴素 | 关注 → 反应 的简单回归 | 啥都没控 | baseline 相关 |
| + 公司固定效应 | 只用**公司内**变化(同一家公司,关注高于自身常态的那些事件) | 时不变的公司质量(好公司恒定被多关注) | **fixed effects**；selfz 已是"相对自身" |
| + 时间固定效应 | 控同期市场环境 | 牛熊/财报季共同冲击 | two-way FE |
| + 同期基本面/事件类型控制 | 控"这季度业绩好→既多关注又反应好" | 时变的公司特定冲击(最难的混淆) | confounding/选择偏误 |
| + 聚类稳健 + WCB | 9 家公司,少簇推断 | 统计噪声 | 复用 `explain_v3_models.py` 的 WCB |

**关键诊断**:如果加 FE 后系数大幅缩向 0,说明原来的"相关"主要是混淆——这个发现本身就值得讲(诚实)。如果系数稳健存活,才有"因果味"。

## 2. 安慰剂检验（因果可信度的核心，SE/纯预测里没有）

真效应要扛过这些"本不该有效应"的测试:
- **时点安慰剂**:把"关注"换成**事件_之后_**的关注——它不该"导致"已发生的事件(查反向因果)。
- **结果安慰剂**:关注不该预测一个**事件前、无信息**的窗口收益。
- **留一公司**:逐个剔除公司重跑,效应不该由某一家驱动。
- **随机事件日**:在非事件日造假事件,不该出现效应。

## 3. 对未观测混淆的敏感性（进阶、加分、可学）

即使控了能观测的,还可能有看不见的混淆。报告:**一个未观测混淆要强到什么程度才能把结论翻盘**(Oster δ 或 E-value 思路)。能讲这个 = 比 90% 的学生项目高一档。

## 4. 复用 vs 新做

**复用(~80%)**:`label_master`(相对反应标签)、`mgmt_institution_count__selfz`(处理变量原型)、面板结构与事件日、`explain_v3_models.py` 里的 FE + 聚类稳健 + WCB 代码、PIT/泄漏校验。

**新做(~20%)**:① 处理变量清晰定义(连续 selfz 或二值"高关注 vs 否");② 同期控制集;③ 逐层 FE 回归 + 系数移动诊断;④ 四个安慰剂;⑤ 敏感性(Oster/E-value);⑥ 诚实识别假设写作。

## 6. 诚实声称边界（务必先想清，写在 S1）

- 这是**观测数据**,不是随机实验;FE/安慰剂/敏感性是**强化**因果解读,不是**证明**。
- 正确表述:"在控制公司与时间固定效应、同期基本面后,异常机构关注与事件后相对市值反应存在**稳健正向关联,且通过了 X 项安慰剂**;在未观测混淆强度低于 Y 的假设下,可作因果解读。"
- 错误表述:"证明了调研导致市值上涨。"

## 7. 要补的知识（按用到顺序）

固定效应(双向) → 选择偏误/混淆 → DiD 思想(本项目用 FE 近似,可对比) → 安慰剂检验 → 聚类稳健 + Wild Cluster Bootstrap(已会) → 敏感性分析(Oster/E-value)。每个"是什么 + 不做会错在哪",照 `PRESENTER_GUIDE` 的学法。
