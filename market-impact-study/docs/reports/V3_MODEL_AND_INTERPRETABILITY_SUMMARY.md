## 2. 对抗性稳健检查（都通过）

| 检查 | test IC | 结论 |
| --- | ---: | --- |
| 全部 test | 0.193 | — |
| 按 (公司,事件日) 去重（删 534 条多类别重复行） | **0.163** | 信号在去重后存活，非重复计数假象 |
| 剔除极端值 \|y\|>0.2 | 0.131 | 非异常值驱动 |
| 9 家公司分别 | **全为正 +0.07~+0.35** | 跨异质公司通用，非个别公司 |
| 无 look-ahead 的 raw rel_to_peer（ridge_fe） | 0.215 | 信号非截面秩 look-ahead 造的 |

诚实保留项：
- **R² 仍为负（-0.22）**——这是排序工具不是量级预测器（与"解释相对反应、不预测绝对市值"定位一致）。
- **信号是周期平均性质、非每期成立**。按季度看模型 test IC：2024Q1 +0.28，但 **2024Q2/Q3/Q4 连续三季约 0~负**，2025-26 多在 +0.13~+0.53。且核心的"相对规模"信号在季度层面**频繁变号**（+0.20/-0.30/+0.23/-0.32…）——全面板 WCB 的 p<0.001 是平均偏负，不代表每个季度都成立。2024Q2-Q4 很可能对应小市值/微盘的特定行情（A 股 2024 年初微盘冲击后续），size 信号在该 regime 反向。**故 v3 应表述为"周期平均上有弱而稳健的排序信号，存在多季度失效区间"，而非"每期可靠"。**

## 3. 可解释性：四层证据

### 3.1 置换重要性（树，test IC 掉落）

相对规模 `rel_to_peer_log_total_mv_pre__xsrank` 掉落 0.051，远超其它；其次 `pre_total_mv__xsrank`、`mgmt_institution_count_m180__selfz`（异常关注）、`pe_pre__xsrank`、`rel_to_peer_turnover__xsrank`。树主要靠**相对规模 + 异常机构关注 + 相对估值**。

### 3.2 特征组单独 test IC（消融）

| 组 | 单独 test IC |
| --- | ---: |
| peer_relative | 0.093 |
| management | 0.089 |
| valuation | 0.081 |
| event_text | 0.073 |
| trading_liquidity | 0.034 |
| category | ~0.000 |
| financial | **-0.094** |
| 全部 | 0.193 |

组间互补（合并 0.19 > 任一单组 0.09）。**原始财务单独是负的**——印证早先"raw 财务不带样本外信号"的判断，应只作控制项。

### 3.3 固定效应 OLS + 聚类稳健 SE + Wild Cluster Bootstrap

全面板回归 `winsor(relative_mv) ~ 信号特征 + 公司FE + 年份FE`，按公司聚类（仅 9 簇，故用 WCB 而非渐近 SE）：

| 特征 | 系数 | 聚类稳健 SE | t | WCB p |
| --- | ---: | ---: | ---: | ---: |
| `rel_to_peer_log_total_mv__xsrank`（相对规模） | -0.039 | 0.005 | -7.25 | **0.000** |
| `rel_to_peer_turnover_m20__xsrank`（相对流动性） | -0.013 | 0.006 | -2.29 | 0.089 |
| `volatility_m20`（近期波动） | -0.011 | 0.006 | -1.68 | 0.062 |
| `mgmt_institution__selfz`（异常关注） | +0.003 | 0.003 | 1.09 | 0.068 |
| `mgmt_institution`（关注水平） | +0.003 | 0.003 | 0.99 | 0.221 |
| `rel_to_peer_ret_m60__xsrank`（反转） | -0.003 | 0.005 | -0.50 | 0.662 |

**诚实结论**：只有**相对规模**在严格聚类稳健推断下显著（p<0.001，相对同行越小→事件后相对市值反应越强，典型小市值效应）；相对流动性、低波动、异常关注**边际显著（p≈0.06~0.09）**；关注水平与反转不显著。即 ML 排序信号（IC 0.16）是真的，但用 9 家公司做严格推断时，只有规模锚是无争议的——这正是"ML 能排序 vs 严格推断能背书"该分清的地方。

### 3.4 单事件 waterfall

线性贡献 `贡献_k = 标准化x_k × 系数_k`，对预测最高/最低各 10 个 test 事件导出 Top5 驱动项（`explain/event_waterfall_examples.csv`），可直接做 CFO 单事件复盘。

分组 IC（`explain/grouped_ic.csv`）：业绩信号 0.31、产品创新 0.29、其他 0.21、资本动作 0.17、风险 0.17，最弱管理层 0.08；几乎全为正。

## 4. 怎样把"可解释性"做到强（方法论）

1. **先有信号再解释**：可解释性建立在"模型确有样本外信号"之上；v2 那种 IC=0 的模型解释的是噪声。本项目现在过了这道门槛。
2. **多方法三角验证**：置换重要性（模型无关）∩ 线性系数方向 ∩ 树依赖，三者一致的才写进主结论；只在一处出现的归"不稳定"。
3. **ML 解释 ≠ 因果背书**：用固定效应 + 聚类稳健 + WCB 把"哪些关联经得起严格推断"和"哪些只在 ML 里出现"分开。9 簇下 WCB 是正确（保守）工具。
4. **逐事件可追溯**：每个预测能拆成特征贡献（waterfall），CFO 能看到"为什么这条事件被排高/排低"。
5. **诚实报告边界**：主结论=相对规模稳健 + 一簇边际信号；附录=2024 失效、R² 为负、9 簇推断局限。把"能解释多少、剩下是噪声、什么经得起检验"讲清楚，本身就是强可解释性。
