# 准确率与评估口径指南（对课程评分）

> 2026-06-15。课程《大数据财务分析》评分无 accuracy 硬门槛；ML 模型质量 40% 看"评估方法的**科学性**与预测效果"。本文给出该报哪些"准确率"、为什么有意义、以及一个诚实的反面对照。

## 1. 关键判断：在"相对"目标上裸准确率会骗人

test 相对市值为正仅 40%、为负 60% → **多数类基线准确率 0.596**。因此：

| 不要当头条的指标 | 值 | 原因 |
| --- | ---: | --- |
| 整体方向准确率 | 0.543 | 低于 0.596 基线 |
| 三分类准确率 | 0.461 | 类不平衡 |
| 清晰波动二分类准确率 | 0.542 | 低于基线 |

裸准确率不是这个问题的合适指标；硬报会显得"不如瞎猜"。

## 2. 该报的"有意义"指标（都打赢基线）

| 指标 | 值 | 含义（PPT 话术） |
| --- | ---: | --- |
| ROC-AUC（涨/跌排序） | **0.59** | 排序能力，>0.5 即有真实信息 |
| Spearman IC | **0.22** | 预测排序与真实排序相关 |
| 分位首尾差（quintile lift） | **~8pp** | 排名前 1/5 事件 +3.5%、后 1/5 −4.6%，单调 |
| 高置信方向准确率@30%覆盖 | **0.65** | 只对最有把握的 30% 事件下判断，准确率 65%>基线 |
| 最高风险十分位精确率 | **0.78** | 标"高危"的事件 78% 实际下跌（基线 60%） |
| 负向冲击 recall / PR-AUC | 0.53 / 0.59 | 风险预警能抓过半负向冲击 |

主话术：**"模型整体方向准确率不超过 naive 基线——这是近有效市场相对反应的本质；但它在最有把握的 30% 事件上方向准确率 65%，AUC 0.59，标为高危的事件 78% 确实下跌，且把事件按反应稳定排序、首尾差 8 个百分点。"**

## 3. 诚实反面对照：大波动检测失败（强化"评估科学性"）

测试"能否预测事件是否引发大反应 |rel|≥阈值"：

| 阈值 | 基线acc | acc | AUC | PR-AUC |
| --- | ---: | ---: | ---: | ---: |
| ≥7%（均衡） | 0.528 | 0.499 | **0.498** | 0.496 |
| ≥10% | 0.682 | 0.562 | **0.506** | 0.316 |

**幅度不可预测（AUC≈0.50）**。原因：模型信号是"规模/关注度/流动性 → 收益**方向**"的风险因子倾斜，不是**波动率**预测器。所以方向有弱信号、幅度没有——这是内部自洽的，且是科学评估的好材料（试了多种框架、报告了什么有效什么无效、并解释机理）。

## 4. 对应评分项

- **ML 模型质量 40%（评估科学性）**：多指标（MAE/IC/AUC/PR-AUC/lift/混淆矩阵）+ 时间外测试 + 基线对照 + 消融 + 方向 vs 幅度两框架对照 + 诚实 null（surprise、大波动）。这是本项目最强项。
- **结果解释 20%**：SHAP∩置换∩WCB 三方一致，相对规模 p<0.001；逐事件 waterfall；移为通信案例。
- **选题价值 20%**：相对同行反应控制行业共振、point-in-time 防泄漏，方法新颖。
- **汇报 20%**：用第 2 节话术，主动讲"为什么不报裸准确率"，问答里这是加分点。
