## 重要口径

| 口径 | 说明 |
| --- | --- |
| `keep_code=1` | 只表示人工认为事件有经济含义，不自动提升为主模型样本 |
| `keep_code=0` | 表示不适合进入训练，通常转为案例/审计 |
| `noise_code=1` | 明确噪声或交易机制类事件，降级为 `case_or_audit_only` |
| `category_code=8` | 交易机制/IPO，例如盘中临停、异常波动、上市首日、`N移为` |
| clean-only | 只能做敏感性分析，不作为主训练结论 |
| 回归模型 | 当前只能作为 baseline 结果，不作为有效预测模型宣传 |

## 下一步建议

| 数字 | 任务 | 理由 |
| --- | --- | --- |
| 1 | 新增三分类模型：positive / neutral / negative | 最推荐；比回归更贴合当前标签噪声结构 |
| 2 | 输出混淆矩阵和分类别 F1 | 能看清模型到底识别正向还是负向事件 |
| 3 | 只在 `其他`、`资本动作`、`管理层/投关信号` 上做类别内诊断 | 这 3 类样本量相对够用 |
| 4 | 暂停特征堆叠，先整理报告口径 | 避免把无效回归包装成有效模型 |

建议下一步做 `1 + 2`：新增 `train_classification_models.py`，用同一套时间切分和 enhanced v2 特征，输出 Accuracy、Balanced Accuracy、Macro F1、负向冲击 Recall、混淆矩阵和分类别表现。
