# 人工复核数字填报码表

复核入口：

`data/processed/data_governance/manual_review_numeric_template.csv`

只需要填写前 5 个数字列：

| 字段 | 含义 | 必填 |
| --- | --- | --- |
| `keep_code` | 是否进入主模型 | 是 |
| `noise_code` | 是否噪声/流程事件 | 是 |
| `category_code` | 修正后的事件类型 | 是 |
| `confidence_code` | 复核把握程度 | 建议填 |
| `note_code` | 备注类型 | 可选 |

## 1. keep_code

| 数字 | 含义 | 适用边界 |
| ---: | --- | --- |
| 1 | 可进入主模型 | 业绩、资本动作、订单、产品、风险、投关等有明确经济含义的事件 |
| 0 | 不进主模型 | 停牌、异常波动、上市首日、纯流程公告、无法归因事件 |

## 2. noise_code

| 数字 | 含义 | 适用边界 |
| ---: | --- | --- |
| 0 | 不是噪声 | 可以解释为经营、财务、资本市场或投关事件 |
| 1 | 噪声/流程事件 | 上市首日、盘中临停、异常波动、股东大会通知、董事会流程、持续督导培训等 |

## 3. category_code

| 数字 | 事件类型 | 例子 |
| ---: | --- | --- |
| 1 | 业绩信号 | 年报、季报、业绩预告、业绩快报、利润变化 |
| 2 | 资本动作 | 回购、分红、减持、增持、定增、股权激励、可转债 |
| 3 | 管理层/投关信号 | 机构调研、业绩说明会、互动问答、投资者关系活动 |
| 4 | 产品/技术创新 | 新产品、研发、专利、技术平台、认证 |
| 5 | 客户/订单 | 大客户、合同、订单、合作项目 |
| 6 | 政策/行业 | 政策、行业景气、监管规则、宏观行业事件 |
| 7 | 风险事件 | 诉讼、处罚、风险提示、亏损、问询、负面舆情 |
| 8 | 交易机制/IPO | 上市首日、停牌、复牌、异常波动、交易机制类公告 |
| 9 | 纯流程/其他 | 股东大会通知、董事会决议、监事会决议、持续督导培训、无法判断 |

## 4. confidence_code

| 数字 | 含义 |
| ---: | --- |
| 1 | 很确定 |
| 2 | 大致确定 |
| 3 | 不确定，后续需要再看原文 |

## 5. note_code

| 数字 | 含义 |
| ---: | --- |
| 0 | 无特殊备注 |
| 1 | 极端标签但事件本身可信 |
| 2 | 同窗多事件，难以单独归因 |
| 3 | 标题像流程公告，但可能包含重大事项 |
| 4 | 建议作为报告案例，不进入模型 |

## 快速判断规则

| 看到标题关键词 | 建议填写 |
| --- | --- |
| `盘中临时停牌`、`异常波动`、`N某某`、`上市首日` | `keep_code=0`，`noise_code=1`，`category_code=8` |
| `股东大会通知`、`董事会决议`、`监事会决议`、`持续督导培训` | 通常 `keep_code=0`，`noise_code=1`，`category_code=9` |
| `年报`、`半年报`、`季报`、`业绩预告`、`业绩快报` | `keep_code=1`，`noise_code=0`，`category_code=1` |
| `回购`、`分红`、`减持`、`增持`、`定增`、`股权激励` | `keep_code=1`，`noise_code=0`，`category_code=2` |
| `调研`、`业绩说明会`、`投资者关系活动` | `keep_code=1`，`noise_code=0`，`category_code=3` |
| `产品`、`研发`、`专利`、`认证` | `keep_code=1`，`noise_code=0`，`category_code=4` |
| `合同`、`订单`、`客户`、`合作` | `keep_code=1`，`noise_code=0`，`category_code=5` |
| `问询函`、`处罚`、`诉讼`、`风险提示` | `keep_code=1`，`noise_code=0`，`category_code=7` |
