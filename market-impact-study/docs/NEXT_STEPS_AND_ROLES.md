# 后续人机分工、特征、建模与解释

> 编写：2026-06-14。本文基于第一版 baseline 真实结果与一次全样本信号诊断，给出诚实判断与可执行下一步。结论性数据见 `reports/BASELINE_MODEL_SUMMARY.md`、`reports/SAMPLE_PREDICTABILITY_DIAGNOSTICS.md`。

## 1. 现状的诚实判断

第一版 baseline 的事实：主模型样本 train 300 / valid 34 / test 164，按验证集胜出的是 `dummy_mean`（全局均值），test Spearman IC = 0，特征模型 test R² 全为负。

全样本信号诊断（在带标签 train 3905 / test 1620 上做）进一步定位了原因：

- **不是单纯样本少**。把样本从 300 扩到 3905（带上 overlap 行），HistGBM 的 test 排序 IC 从 ~0.05 升到 ~0.135，但 test R² 仍为 −0.15、MAE 仍劣于均值基线。更多数据把“排序信号”翻倍，但抬的是一个很低的天花板，没有藏着的强信号。
- **标签被极端值主导**。train 偏度 +2.1，14% 事件 |target|>0.2，且几乎所有巨型异常（|target|>0.66）都落在 train（5G/IoT 模组公司）。同一事件还因多类别标签被复制成多行，放大了异常权重。这是树模型 R² 为负的直接原因。
- **真正稳定的特征只有一小簇且偏弱**。136 个特征里只有 16 个是“稠密 + train/test 同号 + |test IC|>0.03”，且都是已知风格因子：事件前机构调研次数 `mgmt_institution_count_sum_m30/90/180`（IC +0.13~+0.17，最好的一组）、规模/流动性/反转类（`log_total_mv_pre`、`turnover/amount_*_m1`、`ret_m60_m1`，负向 IC 0.06~0.13）。
- **看着强的特征是幻觉**。`evt_money_*`、`evt_profit_*` 的 train IC 最高（0.22~0.23），但 96~97% 缺失、有效样本只有几十条，且在 test 上**翻号**。不可信。
- **无泄露**。136 个特征均 `leakage_risk=low`，`_m{N}_m1` 是事件前窗口（已用弱 IC 验证），训练脚本只在 `split=='train'` 上 fit，test 不参与训练。

一句话定性：**20 日相对同行市值反应接近市场有效性残差**，信噪比天然低。项目价值不在“预测得准”，而在“诚实地量化能解释多少、由什么解释、剩下的是噪声”，并把可解释的那一小部分（机构关注度、风格因子、少数高含金量事件）讲清楚。这恰好契合项目“解释而非预测”的定位——但必须把表述从“模型解释了市值反应”降级为“在控制风格因子后，事件前机构关注度等少数信号与相对市值反应存在弱而稳定的关联”。

## 2. 后续人机任务分配

原则：**机械、可复算、可枚举的交给 AI；涉及经济含义判断、口径取舍、对外表述风险的由人定。** AI 可以高质量执行，但不能替人承担“这个结论能不能写进 CFO 报告”的判断。

| 任务 | 主要由谁 | 说明 |
| --- | --- | --- |
| 数据采集、清洗、SSOT 重建、特征工程实现 | AI 主导 | 已有脚本，可复现，AI 迭代成本低 |
| 单变量 IC 筛查、消融、稳健性重跑、图表生成 | AI 主导 | 纯机械计算，人审结果 |
| 标签 winsorize/去重、样本扩充实验、模型调参 | AI 主导，人定口径 | 截尾阈值、是否纳入 overlap 行由人拍板 |
| SHAP/permutation/固定效应+WCB 的执行 | AI 主导 | 前提是先出现稳定样本外信号，否则解释噪声 |
| **事件分类复核、Top 事件经济含义判断** | **人主导** | AI 给候选与证据，人定“这条是不是真有经济含义” |
| **主标签窗口、基准口径（竞品组合 vs 指数 vs 滚动 beta）选择** | **人主导** | 影响全部下游结论，属方法学取舍 |
| **哪些结论进主报告、哪些只进附录** | **人主导** | 涉及对外因果/预测表述风险 |
| **CFO 建议的业务可行性判断** | **人主导** | AI 能给“数据支持哪些动作”，落地与否是业务判断 |

具体节奏建议：

1. AI 先把第 3~5 节的诊断与稳健性实验全部跑完，产出“有/没有稳定信号”的明确证据。
2. 人基于证据做三个关键决定：(a) 主标签是否换更短窗口或改分类口径；(b) 是否接受“弱信号 + 诚实解释”作为最终定位；(c) Top 事件复核到第几批。
3. AI 据此重训、出图、写解释；人复核表述边界与 CFO 建议。

不要让 AI 自行决定“把负 R² 的结果包装成正面结论”——这是本项目最大的诚信风险点。

## 3. 如何找好的特征

基于诊断，方向应从“多堆结构化滚动统计”转向“补真正含信息的预期差信号 + 用对评估方式筛”。

**先治理，再加特征：**

- **去重**：同一事件因多类别标签被复制成多行，必须按事件去重或在评估时按事件聚合，否则异常值被重复计权。
- **稳标签**：对主标签做 winsorize（如 1%/99%）或改用分位数/秩目标；单独审计 |target|>0.2 的极端窗口，确认不是停牌/复牌/交易机制造成。
- **删幻觉特征**：`evt_money_*`、`evt_profit_*` 这类 >95% 缺失的稀疏抽取特征不要进主模型，最多做覆盖到的子样本案例。

**优先补的特征（按预期收益排序）：**

1. **预期差 / surprise 类**（最可能含真信号）：业绩预告/快报幅度 vs 卖方一致预期或 vs 去年同期；超预期方向与强度；这是事件研究里最经典的、与异常收益真正相关的变量，目前完全缺失。
2. **机构关注度动态**：已知 `mgmt_institution_count_*` 是最强稳定特征，进一步做其变化率、环比加速度、是否首次被覆盖。
3. **风格因子作为控制项**：规模、流动性、反转、估值分位——它们 IC 稳定但属于“已知 beta”，作用是**控制**而非卖点，要在固定效应/回归里当控制变量，避免把风格收益误读成事件效应。
4. **文本语义**：当前只有标题级关键词。若要上文本，用公告正文做 embedding 或更细的词典，但必须先证明它在 test 上有增量 IC，否则只是噪声。

**筛特征的标准（关键）：** 不看 train 重要性，只认 **train/test 同号 + test |IC|>0.03 + 有效样本足够稠密**。把这三条做成一张特征准入表，每个候选特征过一遍。

## 4. 模型训练

- **改目标函数与指标**：相对市值反应是排序问题多于回归问题。主指标用 **Spearman IC / 分组方向准确率**，而不是 R²（在低信噪比 + 厚尾下 R² 几乎注定为负，不代表无用）。回归用 MAE 并配 winsorized 目标。
- **扩有效样本**：把 overlap-heavy 行带上 `overlap_flag` 作为特征一起入模（n 300→~3900），已证明能把排序 IC 翻倍。主模型用全样本 + 污染标记，clean 样本只做稳健性。
- **模型阶梯**：均值基线 → Ridge（看线性方向，强正则）→ HistGBM（浅树 max_depth=2~3，强 min_samples_leaf）。不要上 LSTM/深度 NLP/大集成——信噪比不支持。
- **评估纪律**：严格时间外 test；模型选择只看 valid；任何替换均值基线的模型，必须在 test 上 IC 稳定为正且方向分组可解释，否则只进附录。
- **消融的正确用法**：证明“事件/管理层信号在控制风格因子后是否还有增量 IC”，而不是比谁的 train R² 高。

## 5. 后续解释

**前置条件**：只有当某模型/某特征在 test 上出现**稳定**正 IC，才做解释；否则解释的是过拟合噪声。当前 baseline 还没到这一步。

达到前置条件后：

- **SHAP + permutation 对照**：两者方向一致的特征才写进主结论；只在 SHAP 出现、permutation 不显著的，归入“不稳定”。
- **固定效应回归 + Wild Cluster Bootstrap**：用 `relative_mv ~ event_signal + 公司FE + 时间FE + 风格控制 + 竞品控制`，对核心系数做 WCB（9 家公司聚类数少，补公司-年度/公司-季度/月份聚类敏感性）。这是把“弱 ML 信号”升级为“稳健统计关联”的关键，也是简历亮点。
- **单事件 waterfall + Top 误差复盘**：挑覆盖到 `evt_money_*`/`evt_profit_*` 的少数高含金量事件做案例，承认这是子样本案例而非全样本结论。
- **表述边界**（务必遵守 `METHOD_AND_EVALUATION_PROTOCOL.md` §12）：写“在控制风格因子后，X 与相对市值反应存在弱而稳定的关联”，不写“X 导致市值变化”“模型可预测市值”。把“能解释多少、剩下是噪声”当成诚实卖点，而不是缺陷。
