# Market Impact Study — 同行资本运作对我们公司市值影响研究

## 仓库位置与并入说明

本子项目代码物理上托管在 `competitor_study` 仓库内,位于本目录 `market-impact-study/`。
与父仓库共用 `app/services/{embedder,vectorstore,report_indexer,report_pdf}` 的年报 chunk + bge-m3 + qdrant 检索栈,
不另起仓库的理由:**共用 embedder 单例与 bge-m3 预热成本(~5GB),以及一套 hooks/ruff/import-linter 基建**。

## 项目背景

**面向对象**:CFO
**研究范围**:物联网行业 9 家公司过去 10 年的重大事件 → 市值/股价反应
**核心关切**:**资本运作、重大经营事件** 对市值的影响 — 特别是**同行事件如何传导到我们公司**

## 9 家研究对象

| 公司 | 角色 |
|------|------|
| **移为通信** | **我们公司**(研究主体) |
| 移远通信 / 高新兴 / 广和通 / 日海智能 / 锐明技术 / 有方科技 / 美格智能 / 博实结 | 同行业对照 |

## 项目定位(围绕"我们公司")

研究主体不是 9 家公司的平等对比,而是**我们公司(移为通信)视角下的同行影响分析**:

```
移为通信
    ↑
    │ 受影响
    │
    ├─ 同行做了 X 事件 → 我们公司市值如何反应?(传导效应)
    ├─ 我们公司做了 X 事件 → 自身市值如何反应?(自身归因)
    └─ 我们公司 vs 同行做同类事件,反应有何差异?(对标)
```

第一阶段优先做第二个(自身归因),最简单、最快出结果。CFO 改口"先做一个事件看看",demo 范围进一步缩小到**单事件**。

## 方法论核心

**主线(给 CFO)**:事件研究法 + 合成控制法(SCM)→ 因果性的市值反应推断
**副线(取证)**:RAG 语义检索 → 给事件提供年报原文锚点(差异化能力,与 Wind 终端区分)
**辅助(探索性)**:GBoost + SHAP → **作为假设生成器**,触发新研究问题,不作主结论

**LLM 抽取不在本项目**:外部 claw 工具负责从年报抽事件结构化字段,本项目只做"接收 schema 化输入 + 因果分析"。

> 详细方法论见 [METHODOLOGY.md](./METHODOLOGY.md)
