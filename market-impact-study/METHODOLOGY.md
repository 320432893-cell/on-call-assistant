# 方法论选择与边界声明

## 一、为什么是这套方法组合

| 方法 | 角色 | 解决什么 | 给谁看 |
|------|------|---------|--------|
| 事件研究法(Event Study) | **主线** | 事件公告日的「异常收益(AR/CAR)」+ 统计显著性 | CFO |
| 合成控制法(Synthetic Control,SCM) | **主线** | 反事实推断 — "如果没发生这事件,市值会怎样" | CFO(最爱) |
| DiD 双重差分 | 主线(备选) | 控制同期市场系统性影响 | CFO |
| PSM 倾向得分匹配 | 主线(备选) | 处理"事件不是随机发生"的内生性 | 学术严谨性 |
| RAG 语义检索 | **副线** | 给事件提供年报原文锚点(差异化能力,与 Wind 终端区分) | 内部工程 + CFO 取证 |
| GBoost + SHAP | **辅助探索 — 假设生成器** | 找 CAR 看不到的非线性 → 触发新研究问题 → 回到 CAR 验证 | 自己研究、不作主结论 |
| 网络/图谱分析 | 加分项 | 事件传导效应;产业链关系 | CFO 后期 |

> **LLM 抽取不在本项目**:外部 claw 工具负责从年报抽事件结构化字段,本项目接收已 schema 化的输入。
> 理由:LLM 抽取不可复现,事件录入必须人工或固定规则,作为因果分析的输入数据。

## 二、CFO 听得懂的话术

**事件研究法**:
> "我们用学术界主流的事件研究法测算了过去 10 年定增事件对市值的影响。每次事件的异常收益(CAR)经过市场基准调整,并报告 bootstrap 95% 置信区间。"

**合成控制法**:
> "合成控制法通过加权同行业未发生事件的公司构造'反事实'对照 — 这是诺奖经济学家 Abadie 提出的主流因果推断方法。图中虚线展示'如果没定增'的预期股价,与实线对比可清晰看出事件造成的市值偏离。同时我们用 placebo 检验确保方法在金融场景里没出假阳性。"

**RAG 检索**:
> "事件发生前后,我们用语义检索从公司年报里调出相关段落作为原文取证 — 比如定增公告对应到当年年报里的'募资用途'章节,这让 CFO 能直接看到事件背后公司自己的措辞,而不只是看价格反应。"

**SHAP 的正确措辞(必读)**:
> ✅ 正确:"SHAP 作为**假设生成器**,在样本里识别出潜在模式:当事件 X 与事件 Y 同时发生时,模型预测的市值反应较单独事件强 40%。**该模式触发了新假设**,我们回到事件研究法,在 X+Y 同发的子样本上重跑 CAR,确认/否认了该效应。"
>
> ❌ 错误:"SHAP 显示 X 特征对市值最重要。" — 这会被 CFO 当成因果解读,逻辑链断裂。

## 三、关键边界声明

### 边界 1:SHAP ≠ 因果,SHAP 是**假设生成器**而非补充结论

- SHAP 描述的是「模型怎么算的」,不是「市场实际怎么反应的」
- SHAP 在本项目唯一合法产出形态:**触发可被 CAR/SCM 验证的子样本假设**
- 严禁把 SHAP feature importance 排名直接写入报告主结论
- 本项目样本量小(N ≈ 20-90),SHAP 跨 seed 不稳定是**已知问题**,报告里必须用 ≥5 seed 报告 importance 排名波动范围

### 边界 2:信息可得时间(point-in-time)

- 事件日 t0 = **公告时间**,不是事件实际发生时间
- 年报里说"2025-05-12 签合同",但年报 2026-04 才公开 → 真实 t0 是 2026-04
- 任何特征不能用 t0 之后的数据
- 公告时间精确到小时(盘前/盘中/盘后影响 t0 归属)

### 边界 3:跨公司事件口径一致

- 9 家公司同类事件必须用**相同标准**抽取(由外部 claw 工具固定 schema 输出)
- 事件类型分类必须固化为枚举,不能模糊归类
- 例:「定增」要确定包不包括"非公开发行+特殊股东参与"
- 事件 schema 一旦确定,变更需触发**全量重新抽取**,禁止增量打补丁

### 边界 4:样本量警惕(本项目最大风险)

- 9 公司 × 10 年里,**同类事件可能就 20-40 起**(定增更稀疏)
- 同行业横截面相关性高(ρ 经常 0.7+),真实独立样本数远少于表面数字
- **必须做的事**:
  - CAR 标准误用 bootstrap(`scipy.stats.bootstrap`),不用渐近 t 分布
  - 报告里每张表必须显式列样本量 N
  - 任何回归报告 cluster-robust SE(行业聚类)或 Newey-West
  - SHAP 要做就跨 ≥5 seed 报告 importance 排名波动

### 边界 5:合成控制法在金融场景的特殊风险

Abadie 的 SCM 经典场景是**政策外生冲击**(加州控烟、统一货币),反事实组受同期冲击影响小。
**金融场景反过来**:同行业股票相关性 ρ 经常 0.7+,合成对照组里其他 8 家同行受同期行业冲击,反事实图的虚线本身已被污染。

**强制要求**:
- 每个 SCM 主结果必须配套 **placebo test** — 把 SCM 反过来对**没发生事件**的对照公司跑一遍
- placebo 跑出"显著效应"的比例 > 1/N 时,该 SCM 主结果**不能进 CFO 报告**
- 报告里 SCM 反事实图必须同时展示 placebo 分布(灰线带),实线落在 placebo 分布外才算可信

### 边界 6:行业基准选择

- 不用沪深 300(太宽,与物联网相关性低)
- 不用申万通信指数原始版(基准里含 9 家自己 → β 是对自己回归)
- **使用**:申万通信指数**剔除 9 家研究对象后等权重新构造**,或 Carhart 4 因子模型
- β 估计窗口必须用 **rolling 250 日**(滚动 β),不用全样本静态 β
- 理由:2015 股灾、2018 中美、2020 疫情、2022 注册制等系统性冲击导致 β 不稳定

### 边界 7:A 股价格数据假设

- 假设个股价格数据已完成停牌/ST/涨跌停/分红除权清洗(tushare 拉取后处理)
- 若需重新处理异常数据,参考全局规则 `.ai-config/rules/delivery/data.index.md`

## 四、技术栈

| 阶段 | 工具 |
|------|------|
| 事件研究法 | Python + pandas + statsmodels + scipy(bootstrap) |
| 合成控制法 | `pysyncon`(自带 placebo)/ 备选 `causalimpact` |
| DiD / PSM | `linearmodels` / `statsmodels` / `pymatch` |
| RAG 检索 | sentence-transformers(bge-m3) + qdrant(共用父项目栈) |
| GBoost | XGBoost / LightGBM(CPU 训练足够) |
| SHAP | shap(必须跨 ≥5 seed) |
| 报告输出 | Jupyter notebook + nbconvert(HTML 互动 / PDF 静态) |
| 数据采集 | tushare(积分充足) |
| 网络分析 | NetworkX + PyVis(后期) |

```
报告 v1(Jupyter notebook → HTML / PDF 双输出)

├─ Executive Summary(CFO 30 秒看完)
│   - 核心结论 3 条 + 样本量声明
│   - 一张总图:9 家公司事件影响热力图
│
├─ 第一部分:事件研究法主结果
│   - 每类事件的平均 CAR + bootstrap 95% CI + 样本量 N
│   - 合成控制法对照图(含 placebo 分布带,CFO 最爱)
│   - 跨公司差异分析(cluster-robust SE)
│
├─ 第二部分:竞争对手深度对比
│   - 雷达图 + 时间轴

│   - 同行事件 → 我们公司市值传导
│
├─ 第三部分:探索性发现(明确标注为辅助)
│   - GBoost + SHAP 假设生成器:列出触发的新假设 + 子样本验证结果
│   - **不在本部分下任何主结论**
│
├─ 第四部分:方法论附录
│   - 边界声明(本文档)
│   - placebo test 结果

└─ 附录:RAG 检索结果
    - 每个事件配套年报原文锚点(用于 CFO drill-down)
```

## 六、可视化优先级

### 必有(CFO 必看)
1. **合成控制法图(含 placebo 分布带)** — 每个核心事件一张
2. **CAR 事件窗口图** — 标准事件研究法图,带 bootstrap 95% CI
3. **9 公司热力图** — 行(公司) × 列(事件类型) × 颜色(平均 CAR),底色注 N
4. **事件时间轴** — 交互式 + 市值曲线(plotly,HTML 输出)
5. **竞争对手雷达图** — 资本运作活跃度 / 战略调整 / 大客户依赖 / 研发投入 / 股东稳定性

### 加分项
6. **预警 dashboard** — 对手发生 X 类事件时自动高亮(规则触发,不需 LLM)

## 七、绝对不做的事

- ❌ 把 SHAP 结果作为「事件因果影响」的主结论
- ❌ 用随机切分代替时序切分
- ❌ 用全样本统计量做特征标准化(统计量泄漏)
- ❌ 用未公开的事件信息做"预测"特征
- ❌ 没有置信区间和样本量声明的回归结果
- ❌ 9 家公司样本量警告缺失
- ❌ SCM 主结果不配套 placebo test
- ❌ 用 LLM 自动抽取事件后直接进入因果分析(LLM 抽取不可复现,事件录入必须人工或外部 claw 固定 schema)
- ❌ 报告基准用沪深 300 或申万通信指数原始版(基准污染)
- ❌ 报告里出现 LLM 自动归因 / 自然语言查询界面(LLM 不在本项目代码内)
