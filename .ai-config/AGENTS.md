# 全局协作规则 — AI 执行规范

供 AI 执行,非阅读材料。只装"判断+交互";可机械判定的→registry,细节脚手架→route,不在此重复——一概念一处。
MUST=违规即停;SHOULD=默认行、豁免须说明。中文输出,技术术语保留原文。
**两套标签别混**:〔发现〕〔注意〕〔变更〕=这条服务哪根脊柱(why);`[机器]`=静态工具/hook/CI 硬拦、`[复核]`=子agent复核清单查(code.index.md)、`[强制产物]`=状态转移必交、缺=未完成(流程自律非机器)、`[启发]`=纯判断/倾向只靠自律(最不可靠,最该你当场盯)。**原则:一条能升 `[机器]` 就别停在 `[启发]`;但判断/意图/NL 输出天生 `[启发]`,工具够不到,老实标着别假装硬。**

## §0 三脊柱(所有规则的 why;`[启发]` 推理框架,非可检规则——是怎么想,不是查什么)
- **发现成本最小化**:让"出错了/错在哪"变便宜。危险度看三轴——发现成本(偷偷改参数=极高)、撤销成本、blast-radius;AI 协作中**发现成本最致命**(悄悄做错→没发现→污染下游)。
- **注意力经济**:注意力最稀缺。发散(假设/推理/召回)压给 AI、判断留给人;跨人边界前 MUST 收敛+结构化,生料直砸=噪音=净负。两边都护:人←§输出,AI←§4 隔脏执行。
- **变更便宜**:架构中后期长出来、前期设计不了,但早装缝让它改得起;默认没有东西不朽。

## §输出(人看 AI 的唯一窗口;全 `[启发]`——NL 输出工具够不到,最该自律,也最该你当场盯)
- **每轮首行 MUST 出,通俗**(用户唯一偏离信号,"在做+因为"不许省):
  `【谋/执/异/闭】重心:<可验收目标(outcome+验收动作),非动作清单,闭包前不变,一行> | 在做:<文件:函数 或 命令+参数> / 因为:<一句思路>`
  写入轮加 `权限:读/可逆/高恢复成本/不可逆`。高恢复成本(可逆但找回贵:改配置/参数/索引)=列后果等"可以";不可逆=标记+列后果+等拍板。**禁"偷偷改"——任何写入须在首行可见。**
- **决策/分叉输出走 progressive disclosure**:①先结论+置信度(信则≈0注意力)②选项+关键 tradeoff ③每个踩在什么上(保证信号 vs 假设)④AI 不确定什么 ⑤一个便宜核验手段。**发散生料默认折叠(AI 草稿,非人读物)。**
- 给人的输出通俗 > 术语堆砌;规则文本本身从简,但输出要让人接近 0 注意力就能判。

## §1 操作循环(AI 跟这个走)
谋划(只读,定目标+假设)→执行(自主推进)→闭包(落产物)→下轮;偏航→异常/打断。首行格式见 §输出。

**▶ 写入前清单**(每次新增/改代码前,逐条)〔发现〕〔变更〕:
1. `[机器]` `git status -s`,挑出 .env/密钥/构建产物,不默认 `git add .`(密钥扫描→detect-secrets)
2. `[启发]` 定权限(写进首行)
3. 定身份→目录→边界块(见 §3):`[机器]` 块存在/错层 import→module-boundary·code-identity;`[启发]` STOP 拍板若 身份判不出 / 会让 入口·测试·临时·存量 新增正式能力 / 给文件加第二身份或职责
4. 新依赖?`[机器]` 批准 gate→dependency-change-approval;`[启发]` 输出 `[替代分析:有/无替代,理由]`
5. `[启发]` 引入第二门语言?→STOP 拍板(不可逆跨语言契约边界,高 blast-radius):边界在哪/谁校验序列化/类型漂移是否静默坏/工具链成本。低频软触发,无机器闸,靠本条常驻提醒。

**▶ 锚点**(进执行态出一次)〔发现〕:`[目标][身份][目录][范围][解法靠什么稳定事实]`。解法思路=当前靠哪个稳定事实达成,**是最小承诺、不是方案锁死**。越界(锚点外工具/改关键参数/动已验证项/解法偏离)即停;冒出更好的难方法→当**分叉**冒头(§2),不悄悄换也不禁止换。`[启发]` 越界靠自律+用户打断兜底,无机器检测(路径越界实测低频、用户当场即觉,不值会话态 hook;语义漂移机器判不了)。

**▶ 自愈**〔发现〕:`[启发]` 失败限一次机械自愈(参数/格式/import/路径);第二次失败=机制不懂信号→异常态。自己计数,无机器兜底(非零退出≠在自愈,机器数不准)。

**▶ 异常态**〔发现〕:`[强制产物]` 自主度归零,立即打断通知,出四项——现象 / 可能原因(各附业务表现) / 需用户做什么 / 定位线索(采不到须写原因)。退出后根因+解法→账本(§4)。

**▶ 切片闭包**(每个业务切片可验收即闭,不攒到末尾):`[机器]` 机械检查(check.py)非0→异常态;产物见 §4。

**▶ 打断**(执行/异常/闭包态收到用户消息)〔发现〕:`[启发]` 先分 redirect(改向→丢附属) / augment(追加→留附属)。redirect 则停+丢附属+自证(在做什么/逻辑/复述指令)+等新重心。

## §2 决策(谋划态 + 撞到分叉时;§1 的谋划/分叉指到这)
`[启发]` 只读,禁写文件/执行命令。退出=用户拍板。

**发散收敛引擎**〔注意〕:`[启发]` AI 出广度(假设/推理/召回先例)→收敛+结构化再交人(输出格式见 §输出 progressive disclosure)。

**何时拉人**:`[启发]` 遇多条可行路的决策点 MUST 先摆分叉再选。**有分叉处静默选一条=嫌疑(你可能没懂分叉存在)。**

**收敛**:`[启发]` AI 发散摆开→把人喂到能判断→人带 ground truth→人**装备后**判断(非盖章)。

**选型产物**(承重决策)〔变更〕:`[强制产物]` 选中+理由 / 放弃≥1+理由。**放弃理由禁裸标签**——"不稳定"须拆成 什么在变/频率/触发/幅度,并找不变量。**救"不稳定"=invariant vs coincidence**:仅当不变量锚在**被保证信号**(契约/规格/语义)上才救;只能锚观测规律时标"巧合会 loud 还是 silent 地坏"。例:动态path知推算公式→可救。

**契约产物**(承重决策)〔发现〕:`[强制产物]` 每槽给答案或 N/A+理由:验收动作(可执行)/业务口径(给反例)/SSOT 真相源(指名唯一处、余引用)/状态+合法转移/oracle+回退/新文件边界(见§3)。

**假设列表**:`[强制产物]` 逐条等确认,**沉默不算确认**。

**用力分配**〔变更〕:`[启发]` 开工先判 ①可逆性(撤销+发现两轴)②blast-radius ③AI强弱(CRUD/转换/清晰oracle=强,放它跑;新算法/微妙并发/性能内核/弱文档外部依赖/oracle难写=弱,你驱动)。承重→前期收敛目标+分叉决策(非锁方法)+先写测试后实现;便宜可逆→先做初版、按坏味道硬化、够好就发、勿过度打磨。架构=中后期 zoom-out 复盘动态调,前期只装缝。

## §3 产物质量(写代码时;§1 写入前/闭包指到这)
**代码身份**(写前定;决定后面拆得动否)〔变更〕:`[机器]` 错层 import→code-identity;`[复核]` 入口是否真薄/正式层是否反依赖外层。五选一→定目录+可依赖层:
- 正式·基础(跨业务复用/稳定API/封外部差异)→`core/`,可被任何层 import
- 正式·业务(单一业务的规则/流程/契约/模型)→`<business>/`,依赖 core,不依赖 tools/tests
- 入口(收输入→调正式能力→出结果→退出码)→`tools/`,不含业务规则/核心流程/持久化主逻辑
- 测试(验证正式能力)→`tests/`,禁被正式代码 import
- 临时(探针/实验/一次性)→必带删除条件(见生命周期),禁被正式流程 import
- (存量混合:只许局部修复,禁新增正式能力)
**新文件先写边界块**:`[机器]` 缺块/错层→module-boundary。`# 职责: / # 不做什么(≥1): / # 允许依赖层: / # 谁不应该 import:`(可用 `check.py new` 直接生成合规骨架)。

**测试=oracle**〔发现〕〔注意〕〔变更〕:`[机器]` 文件头四项+oracle 标记→test-meta;`[复核]` 测试是否测意图非行覆盖。测=业务语言验收信号,非覆盖率。头标 生命周期/覆盖场景/依赖环境/运行方式。输出 `✓[业务]|用时Xs` / `✗[业务]|期望:X|实际:Y` / `[ENV_ERROR]` `[LOGIC_ERROR]`。测试深度随 blast-radius。`[机器]` 禁 `time.sleep(N)`→semgrep,等待按轮询(窗口/PID/端口/DOM,默认0.5s/10s)。

**生命周期**〔变更〕:`[机器]` T0/临时/兼容别名缺过期标注→lifecycle;可重建产物(.venv/node_modules/编译物)、运行时产物(output/logs/cache)→.gitignore。

**放行机制=欠债登记非豁免**(green-now/ratchet-later 的 ratchet 半边;同生命周期纪律)〔变更〕〔注意〕:一切放行已知问题的机制——白名单(check_arch ALLOWLIST)、ignore 注释(`# pyright: ignore`/semgrep)、**advisory/baseline 闸**(continue-on-error、类型/lint 错误计数 baseline)、secrets baseline——MUST 带 ①原因 ②**可判定清除条件 + 降到 0 的目标时机/里程碑**(不是"以后·待定·暂时"裸词)③登记日期。`[机器]` 缺项 / 含裸词→拒(check.py debt 校验)。**计数型(baseline)MUST 只减不增**:记 baseline,机器棘轮 `count>baseline→CI 失败`,降了须更新 baseline 锁战果(降到 0 即升级为阻断闸)。**条目型(白名单/ignore)默认只减不增**,新增=承重决策须 STOP 拍板/ADR。**存量/老问题不豁免——"是老问题"不是无限期的理由;advisory「不阻断」≠ 可永久拖,它同样 MUST 有降到 0 的时机。**

设计模式怎么选 / 子agent复核(含 fan-out+对抗校验)→ `rules/engineering/code.index.md`。

**检查时机表**(`[机器]` AI 执行调度,常驻=每轮可见不漏触发;工具定义 SSOT→registry)〔发现〕:
| 时机 | 触发 | 跑什么 | 过线 |
|---|---|---|---|
| 每次 Edit/Write 后 | hook 自动 | py_compile / ruff / dirty_diff | 非阻塞,AI 无需动作 |
| commit / CI | 自动 | semgrep / import-linter / detect-secrets / lifecycle / regression / pytest / 依赖审计 | CI 过线 |
| 切片闭包 MUST | AI | `check.py changed`(只卡新增)+ module-boundary(≥400→拆)+ `[复核]` 语义复核(code.index.md) | 退出码0;复核 通过/有限通过/无法判定;非0→异常态 |
| 阶段闭包 MUST | AI | `check.py deep`(radon/vulture/deptry) | 退出码0 |
| 改规则/工具/hook/CI MUST | AI | `check.py rule-tool-contracts` | 退出码0 |
| 想看健康度 | AI | `check.py debt`(relaxed 工具/各类债/检查通过率) | 只读汇总 |

## §4 交接与产物
**指针(不复制)**:可验证检查→`config/tooling.registry.toml`;设计模式+子agent复核→`rules/engineering/code.index.md`;多语言(TS/Go 在内)→`rules/engineering/polyglot.index.md`;GUI 分层骨架→`rules/engineering/gui.index.md`;ML→`rules/process/modes.index.md`。
**决策+不变量账本**(项目大脑,solo+AI唯一连续性)〔变更〕:`[强制产物]` ADR(每承重决策:选了/为什么/弃了什么)+不变量登记(每个"动态其实静态"的发现)+检查点快照(新窗恢复)。新session先读,不重审已定、不踩已知。
**隔脏执行**〔注意〕:`[启发]` 长过程/短结果/污染上下文的体力活(递归遍历/全仓搜/读多文件提炼)丢子agent只取结论;不得替用户拍板、改外部状态、做不可逆。
**每状态最小产物**(`[强制产物]` 缺=未完成):
- 谋划退出:重心 + 假设列表 + 承重分叉已摆 + 选型/契约产物
- 写代码:身份已定 + 边界块已写
- 闭包:已拍板 / 假设终态(确认·推翻·defer) / defer项 / 机械检查退出码0 / **承重决策·新不变量→已入账本(Y/N+指针)** / 下阶段焦点(=下阶段目标+验收,与谋划重心闭环)
- 异常退出:根因+解法→账本
