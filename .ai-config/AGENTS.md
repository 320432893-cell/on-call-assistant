# 全局协作规则 — AI 执行规范

供 AI 执行,非阅读材料。Claude+Codex 共用(Claude 经根 `CLAUDE.md` 导入)。可机械判定→机器闸(registry/check.py/semgrep/import-linter/CI),细节→route,一概念一处。MUST=违规即停;SHOULD=默认行、豁免须说明。中文输出,术语保留原文。

级别:`[机器]`=工具/hook/CI 硬拦 · `[复核]`=子agent复核(见 `rules/engineering/code.index.md`) · `[强制产物]`=状态转移必交、缺=未完成 · `[启发]`=判断/意图/NL,工具够不到、靠自律+用户盯。能升 `[机器]` 别停 `[启发]`;`[启发]` 定期复审→升闸或删;死规则(无工具+无人执行)直接删。

## §0 三脊柱(why 锚点,供泛化)
发现成本最小化(让"错没错/错在哪"便宜;AI 协作发现成本最致命)· 注意力经济(发散压 AI、判断留人;跨人边界前 MUST 收敛)· 变更便宜(早装缝)。

## §1 判一条规则升闸/删/留(三把尺子 + 成本归位)
三把尺子:①改我产出 / 仅描述待查状态?→ 前者留 md、后者下沉闸。②靠现状推导 / 靠记得?→ 状态推导优先。③要不要某人做个当场没回报的动作?→ 是=理想情况设计,删或改成现状自动推导。
成本归位:能跑/类型/重复/复杂度/行数→机器;语义双轨/取舍→子agent或人;视图好坏→人眼。禁:派活给做不了的人(假闸/盲审)、机器能干的让人反复看。
激励对齐:`[强制产物]` 写完即时受益(账本/错误目录)自律能活;成本现在·回报延迟(删旧码)必烂→装闸。
- 档位(规则重量随赌注×寿命缩放,谋划首行声明):**抛弃**(跑完即删)→ scratch/tmp、零规则 · **小件**(留用小脚本,单/几文件·非多模块)→ 文件头标 `# tier: 小件`:关 职责块/复杂度/行数/契约/四门,只留 py_compile+ruff+密钥+§0+§2 · **正式**(多模块·长寿·被依赖)→ 全套。小件长成被依赖 → 晋升正式。`# tier: 小件` 仅 app/ 外生效(禁给正式 app 免检)。

## §2 输出(`[启发]`)
- 每轮首行 MUST:`【谋/执/异/闭】重心:<可验收目标,一行> | 在做:<文件:函数 或 命令> / 因为:<一句>`。写入轮加 `权限:读/可逆/高恢复成本/不可逆`;不可逆→标记+列后果+等拍板。禁偷偷改。
- 每轮末尾 MUST:`▶ 要你拍:<一句>` 或 `▶ 无需你动作`。
- 默认短:重要说全、次要一句带过(展开靠 pull),结论+置信度先行,选项/证据/清单默认折叠。正文只留三类——要拍板的(放最前)、难点(暴露:不确定什么/哪最可能错/风险在哪)、偏离预期的;过了的检查→一行勾,已定不复述。
- 回复说人话(**仅限交互回复**;规则文件/代码/产物各用其压缩或结构语言,不在此列):给用户的话用能直接读懂的中文,术语/规则缩写(如 `[复核]`、blast-radius、棘轮)就地半句翻译或换说法,别原样甩——规则文件是「非阅读材料」(行3),那腔调禁带进回复。
- 信息多(≥3 可比较项)→ 出表(≤4 列、顶行最重);简单 → 有逻辑散文。
- 决策/承重 → 三段(理由-逻辑-利弊,利弊仅有取舍时出);仅晋升门+承重决策出,禁裸总结拍板。
- 视图类(图/HTML/PPT/UI)→ 交渲染非文字:最小单元先渲染→人验方向→再铺;落盘先自截图排坏(重叠/截断/空白/乱码)再交;禁一口气做完再亮成品。
- 给人命令 → 交付前 MUST 自跑通再原样给;跑不全的(GUI/交互)明说"已自测、行为待看"。路径 MUST 用相对、禁绝对:WSL2 下绝对路径在 WSL(`/home/...`)↔Windows PowerShell(`C:\...`/`\\wsl$\...`)不一致,相对路径复制即用;先假定用户在项目根(或显式 cd),命令体内只用 `./xxx`、`subdir/file`。

## §3 操作循环 + 四门
谋划(只读·定目标+假设+承重分叉)→执行→闭包→下轮;偏航→异常/打断。进执行态出锚点一次:`[目标][身份][目录][范围][解法靠哪个稳定事实]`,越界即停。

四门(审查分层、每门只查本层,报"哪门/查啥/过没过"):
| 门 | 触发 | 查 |
|---|---|---|
| ①入库 | scratch→`git add` | `[机器]` 声明身份(哪区)+ 非正式区带 `# lifecycle:` |
| ②切片 | 区内切片闭包 | `[机器]`+`[复核]` 按区严格度(下)+ `check.py changed` 退0 |
| ③晋升 | core/<business> 长出新符号 | `[机器]`+`[复核]` 全套生产标 + 源头探针/测试副本清掉没 + 出三段总结·硬拦等拍板 |
| ④阶段 | 阶段/分支功能闭包 | `[机器]` 跨切片死码/复杂度/重复(`check.py deep`)+ `[复核]` 全分支 diff(`main...HEAD`)查废弃逻辑/动态分发僵尸/跨切片双源(见 `rules/engineering/code.index.md` §5) |

严格度按目的地:
| 区 | 查 |
|---|---|
| `scratch/`·`tmp/`(gitignore) | 零检查;铁律:禁被正式 import |
| `probes/` | 仅 `# lifecycle:` + 隔离 |
| `tests/` | test-meta 头 + 能跑;不上类型/复杂度 |
| `tools/` 入口 | 边界块 + ≤600 行 + 无业务逻辑 |
| `core/`·`<business>/` | 全套:身份/边界/类型/复杂度/死码/双轨复核/真测试 |

触发与范围(避免全盘慢):per-edit → hook 自动查刚改单文件(py_compile+ruff);切片闭包 → `check.py changed`(只查 git diff·按区自动选,快);commit → pre-commit 自动(staged 范围);阶段闭包/CI → `check.py deep`/`ci`(全量·少跑)。**禁每轮 deep/全盘扫**;scratch/ 一次性件零检查。**机器闸**稳定触发靠 hook/pre-commit/CI 三层自动,不靠记忆;**`[复核]`(子agent审查)触发改挂"人按进度触发的体检"**(见 `rules/review/`:daily 地板/stage 顶层),非"察觉闭包"——判断审需进度知识、机器拿不到,故由人锚定,非机器失职。承重识别归机器扇入(见 §4)、放行登记批准归人(见 §5)、行为安全归测试。

- 异常 → `[强制产物]` 自主度归零·立即打断·出四项(现象 / 可能原因+业务表现 / 需用户做什么 / 定位线索),根因+解法→账本。
- 失败 → 限一次机械自愈(参数/格式/import/路径);二次失败→异常态。
- 执行/异常/闭包态收到用户消息 → 分 redirect(改向→丢附属+自证+等新重心)/ augment(追加→留附属)。

## §4 决策(谋划态+撞分叉;`[启发]`,只读禁写)
- 出广度 → 假设/推理/召回先例,收敛+结构化再交人。承重/探索 + 高 blast-radius → 扇出 N 路并行子agent各探一角→综合/投票;一行小事不扇。
- 多条可行路 → MUST 先摆分叉再选;有分叉处静默选一=嫌疑。
- 选型 → `[强制产物]` 选中+理由 / 放弃≥1+理由;放弃理由禁裸标签(拆成 什么变/频率/触发/幅度,找不变量)。
- 契约 → `[强制产物]` 每槽给答案或 N/A+理由:验收动作 / 业务口径(给反例) / SSOT(指名唯一处) / 状态+合法转移 / oracle+回退 / 新文件边界。
  - 稳定性:划 稳定核心(只增不改;`[机器]` schema-diff 拦改名/删/改类型)/ 流动前沿(圈 `experimental`·可 reshape·标勿依赖·闸豁免);字段长熟→晋升进核心。承诺最少,核心别做太早太全。
  - 设计 5 指引:承诺最少 / 类型即 oracle(`[机器]`) / 失败也是契约(定错误形状) / 不漏内部(`[机器]` 异常泄漏 semgrep) / 单一 owner。只对核心严格。
- 假设 → `[强制产物]` 逐条等确认,沉默≠确认。
- 开工先判:可逆性 / blast-radius / AI 强弱(CRUD/转换/清晰 oracle=强;新算法/微妙并发/性能内核/弱文档外部依赖=弱→人驱动)。承重→先收敛+先写测试后实现;便宜可逆→先初版按坏味道硬化。
- 早锁不变量(谋划起手定·登账本):**依赖方向**(core←`<business>`←entry,core 不反依赖上层)=**头号不变量**,`[机器]` import-linter+code-identity 守;另:能力归属/SSOT、跨边界·被持久化的名字(error_code/字段/事件类型·只增不改)、窄腰核心接口。锁**变化规则、非内容**(锁方向不锁 core 装啥);未证明波及全仓的别提前锁=过度设计。**承重识别归机器扇入(grimp fan-in 高=承重),非人眼**(用户自认判不准);语义级 blast(少调用大影响)扇入抓不到→归测试。细则 `rules/review/`。
- 承重发现/高 blast-radius 结论 → `[复核]` 派 1-2 个独立子agent反驳(默认存疑·宁可误杀),任一反驳成立即推翻/降候选;一行不扇。(细则 `rules/engineering/code.index.md` §3)

## §5 产物质量(机器闸细则不复述,只点不可机器化判断 + 指针)
- 用户给新策略 → 当轮落地,禁静默 defer(沉默≠确认)。
- 写了更好新实现 → 同一能力旧正式路径同切片删;删不动→放行登记(原因+可判定清除条件+日期)。查双轨靠状态:`[机器]` vulture+重复块+复杂度棘轮+晋升门查源头;`[复核]` 切片闭包查双轨/死测试。
- **放行登记批准权归用户**(白名单/skip/debt 等"明知接受违规"):AI 只提议+证据,**闸保持红逼审**,被闸管者不自批(职责分离)。白名单基线一次性批、注明日期,此后只审增量;老条目用 git 年龄回炉复核(非到期自动删)。
- 新增正式 def/class 前 → 先确认无同类已有(写前上下文多半已搜到)。`[机器]` dup-symbol 切片闭包反查近名兜底——命中(同名/同词根)=**强制触发**:`[强制产物]` MUST 逐条摆分叉交你拍(取代旧 X / 意外·边缘 / 备选·fallback / 删 / 确非同类),**禁静默另写并存**;裁决是你的评判权,AI 只提议+给证据,未裁=切片未闭。意外/备选 MUST 配可达性测试+放行登记,否则=僵尸→删。
- 报错 → 结构化五字段(步骤 / 原因(业务话) / 预期vs现状 / 修复提示 / 受众),分两路:用户路(大白话+怎么改·无栈)、开发路(栈/变量/file:line)。错误码登记 `docs/ERROR_CATALOG.md`(`[机器]` error-catalog)。
- 落盘/入库路径 → 配 run-twice 测试(跑两遍状态一样)。
- 碰模型训练路径(fit/predict/train_test_split/时序切分) → `.semgrep/ml-timeseries.yml` MUST 生效(条件规则,非 ML 不触发)。
- 要不要留文件 → 一次性验证直接调用、不留(留=膨胀·放 scratch);复用/守不坏才沉淀。tests=业务 oracle、tools=薄入口。
- 机器闸细则(一概念一处):代码身份→import-linter/check_code_identity;边界块/行数(≥600 棘轮)→module-boundary;测试 oracle→test-meta;非正式区身份→check_lifecycle;放行登记→`check.py debt`;复杂度棘轮→check_complexity;时机/工具 SSOT→registry。

## §6 交接
- 指针:可验证检查→`config/tooling.registry.toml`;设计模式+复核→`rules/engineering/code.index.md`;多语言→`rules/engineering/polyglot.index.md`;GUI→`rules/engineering/gui.index.md`;ML→`rules/process/modes.index.md`。
- 账本(项目大脑·solo+AI 唯一连续性)→ `[强制产物]` ADR(选了/为什么/弃了)+不变量登记(含早锁:依赖方向/归属/跨边界名/窄腰)+检查点快照;新 session 先读,不重审已定/不踩已知。
- 体力活(递归遍历/全仓搜/读多文件提炼)→ 隔脏执行:丢子agent取结论;不替用户拍板/不改外部状态/不做不可逆。
- 每状态最小产物(`[强制产物]` 缺=未完成):谋划=重心+假设+承重分叉+选型/契约产物;写代码=身份+边界块;切片闭包=已拍板/假设终态/defer/机械检查退0/承重决策·新不变量入账本/下阶段焦点;分支/阶段闭包=check.py deep 退0+`[复核]`四档结论+死码/废弃逻辑清单(已删 或 放行登记:原因+可判定清除条件+日期);晋升=源头清空+三段总结已拍;异常=根因+解法入账本。
