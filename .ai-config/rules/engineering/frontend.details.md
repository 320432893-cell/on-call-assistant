# Web 前端复杂设计

本文件只在 `frontend.index.md` 命中复杂前端设计时读取。复杂前端任务必须声明 1-2 个主导设计，并产出对应证据；否则按普通实现处理。

## 1. 复杂设计抓手

页面级结构:

- 适用: 页面同时承担请求、状态编排、字段转换、复杂表单校验、大量展示细节，或复用边界变化。
- 应用证据: 页面职责切分表、组件输入输出边界、不拆分会造成的误伤点。
- 不适用: 小页面、一次性页面、只是行数偏长但变化点集中。

前端增强:

- 适用: 新增状态层、缓存层、请求封装、全局错误机制、图表库或大规模组件体系。
- 应用证据: 真实风险、真实执行代价、最小落地形态和失效边界。
- 不适用: 单页面局部需求、单个图表或接口兼容、说不清收益和边界。

复杂异步:

- 适用: 搜索、分页、筛选、自动轮询、批量提交、请求取消、局部错误边界同时出现。
- 应用证据: 并发策略表、过期响应 / 重复提交 / 取消失败处理、错误恢复方式。
- 不适用: 单次请求且无竞态，或错误只影响非关键局部展示。

状态权威源冲突:

- 适用: store、URL query、本地 state、浏览器存储、后端数据同时存在。
- 应用证据: 状态权威源表、同步方向、冲突优先级、存储版本和过期策略。
- 不适用: 当前组件内部瞬时状态，或后端数据只读展示且无前端复制。

数据展示可信度:

- 适用: 任何图表、表格、统计数字和统计口径；复杂展示进入本节。
- 应用证据: 字段、单位、时间范围、筛选条件、统计口径来源和异常值处理。
- 不适用: 纯静态文案、图标、装饰元素，不承载数据含义。

Web 安全和第三方依赖:

- 适用: HTML / Markdown 渲染、富文本、图表 tooltip、下载文件名、token / cookie / storage、第三方脚本。
- 应用证据: 敏感字段清单、注入入口、转义策略、第三方失败降级和隐私边界。
- 不适用: 无用户输入、无敏感数据、无浏览器持久化、无第三方脚本。

## 2. 验证记录

- 复杂前端设计完成后，用 diff + 应用证据复核是否体现主导设计。
- 接口、异步状态、图表、关键页面改动优先做对应组件测试、E2E、截图或定向手测。
- 安全和敏感信息改动要检查页面、控制台、网络响应和浏览器存储。
- 跑不了时写入 taskwork 阶段总结的“未验证”，说明原因和剩余风险。
