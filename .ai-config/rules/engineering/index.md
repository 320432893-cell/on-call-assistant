# 专题索引: 代码与架构语义

本专题处理代码质量、架构边界、后端、前端和桌面 GUI 技术语义。

本文件只做工程语义路由。默认读取最直接命中的一个规则文件，不自动全量加载。

## 触发入口

### 通用代码语义

命中以下任一场景，读取 `code.index.md`:

- 普通代码改动、bug 修复、小功能、局部重构。
- 异常、日志、配置、公共契约、测试语义。
- 不确定是否命中特定后端/前端/GUI/架构规则。

### 架构边界

命中以下任一场景，读取 `architecture.index.md`:

- 架构边界、模块职责、依赖方向、source of truth。
- 脚本转应用、临时方案转长期方案、外部服务调用边界。
- 多模块重构、核心抽象、架构记忆层变化。

### 后端

命中以下任一场景，读取 `backend.index.md`:

- FastAPI / Starlette / HTTP API 路由、请求参数、响应模型。
- 鉴权、权限、事务、后台任务、HTTP 层可观测性。
- 后端接口契约会影响前端或外部调用方。

### Web 前端

命中以下任一场景，读取 `frontend.index.md`:

- Web 前端组件、状态、API 调用、异步数据、错误边界。
- 图表、表格、统计口径、前端安全、关键用户路径。
- 修改 loading、empty、error 等用户可见展示时，再按需路由到 `../delivery/interaction.index.md`。

### 桌面 GUI

命中以下任一场景，读取 `gui.md`:

- 桌面 GUI、本地可视化工具、窗口、UI 线程、后台任务。
- 任务生命周期、状态一致性、关闭行为、日志和诊断入口。
- 交互细节再按需路由到 `../delivery/interaction.index.md`，打包交付再按需路由到 `../delivery/package.index.md`。

## 读取边界

- 机械格式、lint、类型、基础测试优先交给工具，不在 Markdown 中展开。
- 老项目小改优先读 `code.index.md` 和相关代码，不借机升级架构或重写范式。
- 如果任务同时命中架构和具体技术栈，先读最能决定边界的文件；实现细节再按需读取第二个文件。

## 维护重点

- 是否把机械规则下放给工具，把 AI 算力留给语义判断。
- 是否按任务触发 DI、状态机、策略、日志、配置、测试等局部高优先级规则。
- 是否避免老项目中强行套新范式。
- 是否有验证预算，而不是每次全量测试或完全不测。
