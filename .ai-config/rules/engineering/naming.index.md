# 命名约定（tier1，按需读；当可 grep 的意图信号）

触发：新增/改名符号时；写命名检查时读。

**铁律**：每条命名约定**必须配机器检查兜底**，否则名字会撒谎（状态变了没人改名）——这是 §code.index §5 否决 `# expires:` 标签的同一教训。**不收任何无兜底、靠自觉维护的状态命名。**

**分工**："有没有被用"靠 vulture/扇入从**真实用法**算（名字会骗、用法不骗），**别靠命名**；命名只标**用法看不出的意图**（私有/实验/废弃/探针）。

## §1 约定表（每条配 grep 用途 + 兜底检查）
| 命名 | 意图 | grep 用途 | 兜底检查（`check_naming`，亚秒） |
|---|---|---|---|
| `_前缀` | 私有/模块内 | 找内部件 | 跨模块 `from X import _name` = 红 |
| `experimental_`/`_exp` | 流动前沿·勿依赖 | 找不稳定 API | 豁免稳定闸；晋升靠改名（AGENTS §4 流动前沿） |
| `_deprecated`/`_legacy` | 迁移中的旧实现 | **找该删的旧双胞胎** | 必进 debt 登记；过清除期还有 live 调用方 → flag |
| `probe_`/诊断件 | 只诊断·非生产 | 找探针 | 必带 `# lifecycle:` + 不可被 core import |
| `_stub_`/`_wip_` | 有意占位·待填 | 找占位 | **git 年龄 > 阈值仍叫 stub → flag（该填没填=名字撒谎=rot）** |

## §2 "找占位/不用还留着" = 四信号叠（别单靠名）
1. vulture/扇入 → 确实没用（真实用法）；
2. `_stub_`/占位名 → 标"有意占位"（意图）；
3. git 年龄 → 老 stub=撒谎=rot、新=WIP 宽限；
4. 白名单 → "没用但有意留"的登记表**即占位清单**（带理由，grep 它就列全）。

## §3 落地
- `check_naming`（AST/grep 级，亚秒）进 per-commit + 每日；
- **只约束新代码**；存量旧名不强行大改名（违背"改便宜"），碰到再改、慢慢收敛（老项目小改优先局部一致）。
