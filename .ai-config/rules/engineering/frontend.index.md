# Web 前端规则索引

本文件只做前端语义路由。默认停在本文件，不自动读取 `frontend.details.md`。

## 1. 文件定位

触发:

- Web 前端组件、状态、API 调用、异步数据、图表、表格、前端安全。
- 修改用户可见错误提示、加载状态、空状态、关键用户路径。
- 不确定是否属于前端技术语义、交互体验或通用代码语义。

动作:

- 先判断是否只是小展示改动，还是触发 API、状态、图表、安全或关键路径。
- 小改沿用项目现有框架、目录、组件风格，不借机拆大组件或引入新状态层。
- 用户交互细节按需路由到 `../delivery/interaction.index.md`；若已从 interaction 路由回本文件，只处理新命中的 API、状态、图表或安全风险，不反复回跳。
- 通用代码范式、异常、日志、测试语义按需路由到 `code.index.md`。

## 2. 默认轻量判断

以下场景默认只停在本文件，不读取 details:

- 文案、样式、局部布局、小展示 bug。
- 不新增接口调用、不改变状态来源、不改变图表数据、不改变关键用户路径。
- 不涉及鉴权、敏感信息、错误边界。

最低判断:

- 是否破坏既有交互和数据展示。
- 是否需要局部验证、截图、类型检查或组件测试。
- 是否实际触发了 API、状态、图表、安全或交互规则。

## 3. 读取 details

命中以下任一场景，读取 `frontend.details.md`:

- 组件职责、组件拆分、复用组件、页面级编排变化。
- 新增接口调用、字段映射、请求参数、响应字段、状态码、错误结构、鉴权 token / cookie / header 变化。
- 请求生命周期语义变化：loading、success、error、empty 的状态来源、请求取消、超时、竞态、局部错误边界变化。
- 仅改错误提示文案、loading 文案、empty 文案或样式展示，不改变请求生命周期、状态来源、竞态或错误边界时，不因本条读取 details。
- store、URL query、路由参数、组件本地 state、父子组件状态、浏览器存储变化。
- 图表、表格、统计口径、单位、时间维度、异常数据、大数据量展示变化。
- token、secret、调试信息、XSS、HTML / Markdown 渲染、localStorage / sessionStorage / cookie、第三方脚本变化。
- 引入或替换前端框架、状态管理、图表库、请求库、构建工具。
- 改关键业务页面、路由结构、鉴权流程、全局错误处理。

读取边界:

- details 只处理前端技术语义，不替代交互、后端、数据或通用代码规则。
- 不因为普通前端小改就全量读取 details。
- details 中的增强牺牲项只在新增状态层、缓存层、图表库、请求封装、全局错误机制或大规模组件拆分时使用。

## 4. 前后端契约路由

- 后端 API 契约不清、响应字段变化、状态码 / 错误结构变化时，先判断是否读取 `backend.index.md`。
- 前端为了兼容后端临时改字段、默认值、错误结构时，必须说明这是临时兼容、字段迁移还是掩盖后端契约混乱。
- 前端图表、表格或统计展示涉及真实数据口径、单位、时间范围时，按需读取 `../delivery/data.index.md`。
