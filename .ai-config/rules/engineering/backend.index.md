# FastAPI / Starlette 后端规则索引

本文件只做后端语义路由。默认停在本文件，不自动读取 `backend.details.md`。

## 1. 文件定位

触发:

- FastAPI / Starlette / HTTP API 路由、请求参数、响应模型、鉴权、事务、后台任务。
- 修改接口契约、权限、数据库写入语义、HTTP 层可观测性。
- 不确定是否属于后端技术语义、通用代码语义、架构或数据规则。

动作:

- 先判断是否改变外部 API 契约、权限、事务、后台任务或可观测性。
- 小改先读相关路由、service、测试或调用点，优先最小改动和定向验证。
- 通用异常、日志、配置、测试范式按需路由到 `code.index.md`；整体分层和架构记忆按需路由到 `architecture.index.md`。

## 2. 默认轻量判断

以下场景默认只停在本文件，不读取 details:

- 已有接口内部 service 逻辑微调。
- 小 bug 修复。
- 路径解析、参数兼容、文件 / 文件夹支持之类局部改动。
- 不改变路由、鉴权、请求 / 响应结构、数据库写入语义。

最低判断:

- 是否改变外部 API 契约。
- 是否影响调用方、权限、数据、测试。
- 是否需要局部 pytest/httpx、最小复现或手工命令验证。

## 3. 读取 details

命中以下任一场景，读取 `backend.details.md`:

- 路由、HTTP 方法、请求参数、响应字段、状态码、错误结构变化。
- Pydantic、`response_model`、裸 `dict` / `Any`、ORM 对象返回、字段校验变化。
- 登录态、管理员、内部调用、服务间调用、租户、资源所有权、用户身份传递变化。
- 数据库写入、多步写入、事务、commit、schema 变更、迁移、回滚变化。
- `BackgroundTasks`、`asyncio.create_task`、队列、调度器、长任务、同步阻塞 IO 进入 async 路由。
- middleware、trace_id、请求日志、5xx、慢请求、生产排障、错误响应泄漏风险变化。
- API 版本策略、公开接口破坏性变更、权限模型、事务边界、全局异常处理变化。

读取边界:

- details 只处理 FastAPI / Starlette / HTTP API 层语义，不替代通用代码、架构或数据规则。
- 不因为普通后端小改就全量读取 details。
- details 中的后端增强牺牲项只在新增全局机制、重型基础设施或破坏性契约前使用。

## 4. 前后端契约路由

- 响应字段、状态码、错误结构、鉴权行为变化会影响前端或外部调用方时，必须说明兼容影响；必要时读取 `frontend.index.md`。
- 新增或修改 API 时，若前端已有调用方，先查调用点或说明未确认调用方风险。
- 数据库写入、批量更新、迁移、覆盖或对账风险按需读取 `../delivery/data.index.md`。
