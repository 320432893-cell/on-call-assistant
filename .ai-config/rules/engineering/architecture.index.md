# 架构语义规则索引

本文件只做架构规则路由。默认停在本文件，不自动读取 `architecture.details.md`。

## 1. 触发

- 架构边界、模块职责、依赖方向、source of truth。
- 脚本转应用、临时方案转长期方案、外部服务调用边界。
- 多模块重构、核心抽象、架构记忆层变化。

## 2. 轻量判断

默认先判断:

- 当前是否真的改变架构边界，还是普通代码实现。
- 是否涉及稳定事实、架构决策或接力风险。
- 是否需要维护 PROJECT_MAP、AI_HANDOFF。
- 是否会把小改过度架构化。

## 3. 读取 details

命中以下任一场景，读取 `architecture.details.md`:

- 需要项目记忆层优先级、架构变更门、脚本转应用。
- 需要判断边界规则、配置与环境边界、外部服务边界。
- 新增公共复用、跨模块抽象或长期架构产物维护。
- 架构取舍影响多个模块、部署、交付或长期维护。

## 4. 路由

- 通用代码语义读取 `code.index.md`。
- 后端接口边界读取 `backend.index.md`。
- 前端状态 / API / 图表读取 `frontend.index.md`。
- 交付路径读取 `../delivery/package.index.md`。
