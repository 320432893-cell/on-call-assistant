# 救火流程索引

本文件只做救火路由。默认停在本文件，不自动读取 `flow_emergency.details.md`。

## 1. 触发

- 生产事故、线上故障、严重 bug、数据损坏、安全风险。
- 用户明确说“救火 / 紧急 / 线上 / 生产 / 事故”。
- 继续试错可能扩大损害。

## 2. 不触发

- 普通 bug、普通重构、普通规则维护。
- 没有生产、数据、安全或用户现场损害风险。

## 3. 读取 details

命中以下任一场景，读取 `flow_emergency.details.md`:

- 需要判断 P0 / P1 / P2 强度。
- 需要主动协同取证、止血、根因修复、退出条件。
- 有连续失败、猜测修复、可能二次伤害或无法验证修复。
- 需要明确硬红线和完成标准。

## 4. 路由

- 数据损坏或批量写入风险，读取 `../delivery/data.index.md`。
- 生产接口、权限、事务问题，读取 `../engineering/backend.index.md`。
- 信息缺口复杂，读取 `../reasoning/info_guidance.md`。
