# 新项目流程索引

本文件只做新项目 / 新模块路由。默认停在本文件，不自动读取 `flow_new_project.details.md`。

## 1. 触发

- 从 0 到 1 建新项目、新模块、新工具或新架构地基。
- 需求边界不清，需要方案候选、取舍和拍板点。
- 用户说“设计一下 / 重新设计 / 怎么做更好”。

## 2. 轻量判断

默认先判断:

- 交付形态和用户真实验收路径。
- 是小项目、MVP、展示用途，还是中大型长期工程。
- 当前是讨论态、草案态还是用户已拍板执行。
- 哪些问题必须用户拍板，哪些可以先用假设推进。

## 3. 读取 details

命中以下任一场景，读取 `flow_new_project.details.md`:

- 需要阶段门、复杂度分档、交付形态与业务画像。
- 需要假设与风险、架构候选、拍板前骨架。
- 准备落盘新项目、新模块、目录结构、工具链或架构地基。
- 需要区分小项目压缩路径和中大型完整路径。

## 4. 路由

- 信息缺口复杂，读取 `../reasoning/info_guidance.md`。
- 进入风险识别阶段，读取 `../reasoning/risk_reasoning.md`。
- Web 应用读取 `../engineering/frontend.index.md`；后端 API 读取 `../engineering/backend.index.md`；架构边界读取 `../engineering/architecture.index.md`。
