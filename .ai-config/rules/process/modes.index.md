# ML 模式纪律（tier1，按需读）

触发：任务涉及 ML 指标/模型/数据管道时读取。

ML 是"高爆炸 × 低可检测"的最纯实例：指标便宜到一跑就有，却系统性地骗你（泄漏、过拟合验证集、训练/服务特征不一致、分布漂移）。

## 必须先锁的契约层

| 契约 | 要点 |
|---|---|
| 数据切分 | 时间切分防泄漏；训练集不得包含未来信息 |
| 评估协议 + 留出集 | 留出集只用一次；评估协议锁死后不得改动 |
| 训练-服务特征一致性 | 防 skew = 防双真相源；特征定义 SSOT 唯一 |
| "够好"的阈值 | 业务能容忍多大错——**只有用户知道**，AI 不得假设 |

## 该迭代的形状

用哪些特征 / 模型选型 / 超参——信号驱动，不锁。

## 对抗式评估（独有纪律）

主动证明"我这个漂亮指标是假的"：查泄漏 / 在真正未来时段验 / 查训练-服务一致性。

## 三边界映射

- **入口**：数据——泄漏？训练分布 = 服务分布？
- **产出**：泛化——指标真泛化还是自欺？怎么独立证伪？
- **出口**：漂移与回滚

## 第四真相源

遇到真相源装不下三种的（如并发/分布式：真相源是非确定时序，既会撒谎又观测即改变），按生成式问句现场推导：**这一步的真相源是什么？它会不会骗我？**
