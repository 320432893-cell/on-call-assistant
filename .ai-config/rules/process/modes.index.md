# ML 模式纪律（tier1，按需读；只加 ML 特有 delta，全局脊柱/标签梯子见 AGENTS.md，一概念一处不重复）

触发：任务涉及 ML 指标/模型/数据管道时读。

**核心差异（why）**：SE 错误多 loud（编译/测试/崩）；**ML 错误 silent + confident**——泄漏给你漂亮指标、错 join 给你合理的图，模型训练顺利却全错。全局"发现成本最小化"在此**封顶**。本规范两件事：**A/B 防坏**（把无声错变 loud）+ **C/D 产好**（把注意力还给人做判断）。安全闸只让人不当人肉质检，质量在人的判断里长出来。

## §why ML 三脊柱增补（沿用全局）
- **错误无声→发现成本封顶**：每条规则 = 把某个无声错变 loud。
- **防自欺 > 效果**：真 IC 0.2 胜假 0.9；**留出集是最稀缺资源（看一次即污染）**；null 是产物。
- **可复现=可信**：不能复现的结论 = 0。

## §A 防坏·安全闸（能升 `[机器]` 全升——无声错主要入口，硬拦；契约层改=承重，走全局选型/契约产物）
| 闸 | 标签 | 要点 |
|---|---|---|
| 数据切分 | `[机器]` | 时序禁随机切；**留出集只用一次**；选型/调参期禁触；访问计数登记，>1 须说明 |
| 泄漏 | `[机器]` | 特征 `as_of ≤ 事件日`；target 衍生量不进特征；预处理统计（均值/分位/编码）只在 train fit；黑名单 |
| 样本 n | `[机器]` | 每步 filter 记 n，掉 >X% 报警（防 dropna 雪崩：6398→300 那种） |
| 数据 oracle | `[机器]` | row-count / join 基数 / **单位量纲**（万元 vs 亿元）/ 取值域断言；可独算指标抽样复算（CAR 30/30） |
| 训练-服务一致 | `[机器]` | 防 skew = 防双真相源；**特征定义 SSOT 唯一** |
| 复现 | `[机器]` | seed / 库版本 / 数据 hash / n 入 registry；同输入同输出核对 |
| "够好"阈值 | `[启发]` | 业务能容忍多大错——**只有用户知道，AI 不得假设** |

## §B 防坏·审计可见（AI 过程可见可审 = 人看 AI 的窗；ML 里更要命，窗后的错无声）
- **首行增补**：`阶段<EDA/特征/训练/评估/解释> | 指标 vs 基线 on <split> | 留出:未触/触N次`。**禁偷偷碰 test / 换指标 / dropna 掉样本**。
- **锚点增补**：`[目标=预测什么][标签口径][切分][样本范围][信号靠哪个被保证事实]`；越界 = 偷偷扩样本/换标签/碰 test/解法漂成 p-hacking → 停。
- **账本增补**：决策日志（目标/指标/切分）+ **失败登记（nulls）** + 复现快照。
- **三条 ML 反转规则（SE 没有）**：
  1. `[启发]` **太好了=可疑**：指标突然变好（如 0.55→0.9）→ 进**异常态查泄漏**，不是庆祝、不是写进 PPT。
  2. `[强制产物]` **test 访问日志 + 口径冻结**：看 test 前主指标/样本口径已冻；事后改让数字好看 = 违规。
  3. `[启发]` **自愈限一次=反 p-hacking**：结果不对只许查一次机制，**禁反复换种子/阈值/特征凑数**。

## §C 产好·协同循环（正面引擎）
**质量 = 可信 + 有用**（不等于数字高）：①问对问题 ②结果真（可复现/无泄漏/扛攻击）③知道能信几分 ④接得上决策。
循环（人 AI 各半，AI 占②③⑤⑦，人占①④⑥）：
1. **人定框**（问题+成功标准）——质量 80% 在此定，且最便宜改；
2. AI **发散**（特征/模型/假设，比人广）；
3. AI **收敛**（结构化+排序+摆 tradeoff，走全局 progressive disclosure，把人喂到能判，不甩生料）；
4. **人判断**（带 ground truth，非盖章）→ 框更新，回 2 多轮；
5. AI **对抗自证**（`[复核]` 去攻击自己的结果——查泄漏/真未来时段验/去重/去极端/分组/训练-服务一致；**质量最大杠杆**）；
6. **人接现实**（经济上讲得通吗？什么会让它假？）；
7. **诚实记账**。
**对抗式评估（ML 独有）**：主动证"我这漂亮指标是假的"，扛过攻击才采信。

## §D 五个著作点（人不可替代、有意义；缺这层 md 退化成"约束 AI"、人变看门狗）
协调协议：**AI 收敛+装备 → 人著作（带 ground truth）→ 决策承重，入账本**。
1. **提问/目标**：预测什么、为什么重要（相对 vs 绝对）——AI 优化任何目标，但判不了"这是错的问题"。
2. **特征意义**：哪些有领域/财务理论依据，是已知 beta 还是真 insight——意义来自领域不来自数据。
3. **成功标准/主指标**：先于看 test 声明，配基线同框；IC 0.2 算成功还是失败由人定。
4. **信号真伪总判断**：综上我信不信、敢不敢对外——AI 易自信自欺，**人是防自欺的断路器**。
5. **解释→行动**：对外口径、建议可行性、署名担责——私有信息 + 问责，AI 够不到。

## §E AI 强弱分配
- **强（放它跑）**：数据清洗、特征实现、批量消融、出图、网格搜索、EDA 体力、对抗自证的执行。
- **弱（人驱动+盯死）**：目标与指标定义、泄漏判断、信号真伪、口径取舍、结论对外、**因果声称**。
