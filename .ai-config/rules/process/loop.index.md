# 工作循环（tier1）— P0–P4

任何任务（新项目 / 新模块 / 加功能 / 老项目改动）都走这一个循环。新项目与老项目唯一的区别是 P1 的动词：**新 = define（定义契约），老 = discover（从代码读出契约再声明 conform 哪些）**，骨架完全一致。

判据始终是 `AGENTS.md § 0` 风险轴：**不可逆 / 高爆炸低可检测 → 现在锁、即时查；可逆形状 → defer、信号驱动。**

---

## 阶段总览

| 阶段 | 干什么 | 拍板 | 注意力 |
|---|---|---|---|
| P0 定位 | 新 / 老？交付形态 + 验收动作 | 否（太便宜） | 轻，一句话 |
| **P1 锁契约** | 过八槽 + 开放槽，逐项 define 或 discover | **是，唯一集中拍板点** | 重，铺满 |
| P2 最小实现 | 锁定契约下选最简结构，零投机扩展 | 否 | 轻，工人一行 |
| P3 常驻双门 | 每次写入：机械门 + 契约门（`AGENTS.md § 6`） | 否 | 机械零成本，契约碰到才花 |
| P4 信号驱动精进 | 解耦 → 是否重构 → 扩展 → 优化 | 视改动 | 中，信号触发才启 |

P3 不是独立阶段，是贯穿 P2/P4 的常驻层。

---

## P0 定位

- 新还是老？决定 P1 用 define 还是 discover。
- 交付形态 + 用户验收动作 = 终止条件，没有它不进 P1。

## P1 锁契约（核心）

逐项过下列 8 槽 + 开放槽。**全过、可写“N/A + 理由”一行、不许空 / 不许编**。深度随项目缩放，清单一格不漏才是通用性来源。新项目 define，老项目 discover（读出现状 + 声明 conform 哪些；本次改动若违反某条既有契约，当场提出）。

| 层 | 槽 | define / discover 要点 |
|---|---|---|
| 目标 | ① 交付形态 + 验收动作 | 没它就没终止条件 |
| 目标 | ② 不做什么 | 最便宜的防过度设计闸 |
| 契约 | ③ 业务口径 / 语义 | “合法的 X 是什么”，含糊 = 正确地造错东西 |
| 契约 | ④ 数据契约 = schema ＋ SSOT | 形状与“谁拥有真相”是两件事；两个真相源最致命 |
| 契约 | ⑤ 状态契约 = 状态 + 合法转移 | 让非法状态无法表示；定义要锁，实现可从简 |
| 边界 | ⑥ 入口（`AGENTS.md § 6.2 ①`） | 哪些是控制不了的外部输入、在哪校验 |
| 边界 | ⑦ 产出 + oracle（`§ 6.2 ②`） | 哪些会被当答案、怎么独立证伪 |
| 边界 | ⑧ 出口 + 回退（`§ 6.2 ③`） | 哪些写 / 删 / 发布收不回、依赖挂了怎么降级 |
| 开放 | ⑨ 本项目独有的不可逆是什么？ | **生成式问句，不是清单**。固定清单必漏掉项目独有的不可逆点（如并发 / 顺序、幂等 / 重跑、可观测性、schema 演进 / 回填）。这格才让循环真正通用 |

P1 输出经 `AGENTS.md § 5` 收敛成 1–3 个拍板点，用户拍板后才进 P2。

**P1 逃生门（防瀑布）**：有些契约只能先写错一次才能发现。允许一种**显式贴标签的探针 spike**：唯一任务是把契约逼出来，**必须删，不进 P3 门、不允许长大成 v1**。

## P2 最小实现

锁定契约下选最简结构，零投机扩展。形状（模块怎么拆、用不用某模式、抽象层次）全部可逆，**现在不构思，defer 到 P4**。状态机按 ⑤ 锁定义但实现从简。

## P4 信号驱动精进

仅当 v1 跑通、**有真实信号**才启（解耦评估 → 是否重构 → 扩展点 → 优化）。

- **防“defer = 永不”**：P4 MUST 有**真实触发器**（具体 signal + 谁拍），不许“等有空”。要么承认 v1 即产品、提高 P2 标准（不是“最小”是“够格”）；要么明确触发器。二选一明选。
- **扩展 / OCP**：让扩展廉价的不是提前搭架子，是 P1 契约干净。**不搭用不上的 hook**；只为**真实近期**（路线图上、用户明说要来的）变体留最小缝。加新功能 = 重进 P0 → P1（discover）：先问“违反哪条已有契约 / 冒新真相源吗”，不违反就 P2 最简，第二个真实变体到了才在 P4 向 OCP 重构。
- **只记录、不预留**：把“后续最可能变化点”写成笔记，不为想象需求埋钩子。

---

## 闭包接续

阶段切换 / 锁契约 / 换路时按 `AGENTS.md § 7` 闭包持久化。on-call 类项目：**真实事故是最高质量信号**，P4 的真实触发器之一就是“事故 → 回头更新风险表 / 契约”。

骨架与拍板前细化（目录结构、模块职责、接口、数据流、配置 / secrets、测试分层）在用户选定方向后再展开，不在 P1 输出完整目录树。
