# 老项目流程索引

本文件只做老项目改动路由。默认停在本文件，不自动读取 `flow_legacy_project.details.md`。

## 1. 触发

- 老项目 bug 修复、小功能、局部重构。
- 首次修改已有代码，需要沿用既有结构、控制影响面。
- 用户要求接手、熟悉、理解项目后继续改老代码。

## 2. 轻量判断

小改默认只做:

- 确认仓库根、工作区状态和目标文件。
- 先读现状和调用点，不猜项目结构。
- 判断是否触及公共接口、数据写入、架构边界、用户可见行为。
- 沿用局部风格，不借小修复升级范式。

## 3. 读取 details

命中以下任一场景，读取 `flow_legacy_project.details.md`:

- 首次接手或需要建立 / 更新项目记忆层。
- 多文件改动、重构、跨模块调用、公共契约变化。
- 需要体检分级、改前影响图、散弹度判断、A/B/C 走法。
- 工作区已有用户改动、未跟踪文件、生成产物或敏感文件风险。
- 需要改后回扫、AI_HANDOFF 或 PROJECT_MAP 维护。

## 4. 路由

- 新模块或从 0 到 1 设计，读取 `flow_new_project.index.md`。
- 生产事故或数据损坏，读取 `flow_emergency.index.md`。
- 普通代码语义，读取 `../engineering/code.index.md`。
