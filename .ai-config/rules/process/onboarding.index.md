# 接手流程索引

本文件只做接手流程路由。默认停在本文件，不自动读取 `onboarding.details.md`。

## 1. 触发

- 首次接触项目、新模块或陌生目录。
- 用户要求“接手 / 理解一下 / 先熟悉 / 看看项目”。
- 需要建立或更新项目地图、运行方式、核心目录职责。

## 2. 轻量判断

默认先做:

- 完成 workflow 任务前体检。
- 判断需要浅接手、标准接手还是深接手。
- 先做地图测绘，不急着通读所有代码。

## 3. 读取 details

命中以下任一场景，读取 `onboarding.details.md`:

- 需要完整 4 步接手流程。
- 需要写或更新 PROJECT_MAP、AI_HANDOFF。
- 需要判断是否通读、如何通读、哪些问题问用户。
- 基础设施异常、密钥、仓库根、工具链、运行方式不清。

## 4. 路由

- 接手后新增功能 / 新模块，读取 `flow_new_project.index.md`。
- 接手后改老代码 / 修 bug / 重构，读取 `flow_legacy_project.index.md`。
- 通用执行门禁读取 `workflow.index.md`。
