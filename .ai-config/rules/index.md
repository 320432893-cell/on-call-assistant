# 规则专题索引

本目录按专题入口读取规则，不默认全量读取所有 `*.md`。

除 `process/flow_new_project.index.md` 是新项目 / 新模块的事前特定触发流程外，其他专题规则默认都是项目结束后、用户声明后触发的体检规则。普通实现中不要因为存在体检规则就自动读取。

使用原则:

- 先判断是否为新项目流程，或用户是否明确要求体检 / 审查 / 复盘 / 验收。
- 专题入口只做路由和批量维护分组，不复制具体规则正文。
- 已读本文件后仍不确定当前任务属于哪个专题时，按 `.ai-config/AGENTS.md` 的交互规范先收敛信息；仍不确定时问用户一句。
- 新任务、任务目标变化、从讨论进入实现、从实现进入验证 / 交付、用户纠偏或上下文压缩后，必须重新从本文件或阶段闭包判断规则入口。

专题入口:

- `process/flow_new_project.index.md`: 新项目 / 新模块。
- `engineering/index.md`: 用户声明触发的代码语义、架构、后端、前端、GUI 体检。
- `delivery/index.md`: 用户声明触发的用户交互、数据处理、打包交付、浏览器自动化体检。

批量维护顺序:

1. 先遵守 `.ai-config/AGENTS.md`，确认规则怎么改。
2. 再按专题入口批量检查触发条件、已有覆盖、牺牲项和 ROI。
3. 最后只修改命中的具体规则文件，不因索引存在而全量重写。
