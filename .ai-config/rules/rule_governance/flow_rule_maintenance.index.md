# 规则维护流程索引

本文件只做规则维护流程路由。默认停在本文件，不自动读取 `flow_rule_maintenance.details.md`。

## 1. 触发

- 准备新增、修改、删除、压缩、迁移规则文件。
- 修改 hook、settings、memory、规则索引、规则副本。
- 讨论规则应该保留、删除、下放工具、改写成什么形态。

## 2. 轻量判断

默认先判断:

- 当前是讨论态、草案态还是写入态。
- 用户是否明确授权写入。
- 本阶段只处理哪个规则重心，不处理什么。
- 是否需要先读 `governance.index.md` 判断规则怎么写。

## 3. 读取 details

命中以下任一场景，读取 `flow_rule_maintenance.details.md`:

- 需要阶段化维护、讨论重点、发散方式、写入前确认。
- 涉及 hook / settings / memory / 规则索引 / 规则副本。
- 需要执行后反馈、退出条件、完整阶段闭包。
- 用户纠偏、上下文压缩或下一阶段需要重新拍板。

## 4. 路由

- 判断规则层级、索引、hook 准入、工具下放时，读取 `governance.index.md`。
- 修改目标专题规则时，读取目标专题 index。
