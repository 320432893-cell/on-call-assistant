# 浏览器自动化规则索引

本文件只做浏览器自动化路由。默认停在本文件，不自动读取 `web-automation.details.md`。

## 1. 触发

- Playwright / Selenium / RPA / 浏览器脚本。
- 打开页面、点击、截图、抓取、下载、上传、提交。
- 登录态、验证码、iframe、弹窗、新 tab、批量执行。

## 2. 轻量小脚本

以下场景默认只停在本文件:

- 一次性打开页面、读取少量公开信息、简单点击或截图。
- 无登录态、无验证码、无批量循环、无写入或提交副作用。

最低要求:

- 优先使用 Playwright 原生 locator、自动等待和超时。
- 失败时至少保留错误原因和必要截图。

## 3. 读取 details

命中以下任一场景，读取 `web-automation.details.md`:

- 需要登录态、会话恢复、批量抓取、下载、翻页、循环操作。
- 目标页面包含 iframe、弹窗、新 tab、动态加载。
- 验证码、短信验证、滑块、人机验证或高价值系统。
- 表单提交、状态变更、审批、删除、批量写入、重复提交可能产生副作用。
- 需要失败现场自动取证、用户协作取证、进度记录或检查点。

## 4. 路由

- 抓取结果写文件、合并、去重、覆盖用户文件时，读取 `data.index.md`。
- 浏览器自动化工具要交付时，读取 `package.index.md`。
- 前端页面开发读取 `../engineering/frontend.index.md`。
