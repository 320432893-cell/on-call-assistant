# 专题索引: 产品交互、数据与交付

本专题处理用户可见交互、数据处理、打包交付和浏览器自动化。

本文件只做专题路由。默认读取命中的 `*.index.md` 或单一规则文件，不自动读取 `*.details.md`。

## 触发入口

### 用户可见交互

命中以下任一场景，读取 `interaction.index.md`:

- 修改按钮、弹窗、表单、窗口、菜单、快捷键。
- 新增错误提示、加载状态、空状态、成功 / 失败反馈。
- 有后台任务、日志、停止、重试、导出、复制、诊断入口。
- 用户提到交互、体验、好用、F12、调试入口。

### 数据处理

命中以下任一场景，读取 `data.index.md`:

- 读取、清洗、合并、转换、过滤、写出数据。
- Excel / CSV / JSON / SQL / 接口数据。
- 去重、关联、汇总、金额计算、覆盖已有文件。
- 接入新数据源或字段结构不明确。

### 打包交付

命中以下任一场景，读取 `package.index.md`:

- exe、zip、Docker、Web 服务、CLI、HTML 展示页、演示稿交付。
- 版本、依赖、资源、配置、运行环境、分发说明。
- 用户需要在非开发机运行。
- 正式交付、客户现场、生产部署。

### 浏览器自动化

命中以下任一场景，读取 `web-automation.index.md`:

- Playwright / Selenium / RPA / 浏览器脚本。
- 登录态、验证码、iframe、弹窗、新 tab、下载上传。
- 批量抓取、批量提交、自动截图、失败取证。
- 目标系统状态变更或有副作用。

## 文件分工

- `interaction.index.md`: 用户可见交互、按钮四态、窗口承载、诊断取证。
- `data.index.md`: 数据正确性、脏数据处理、复现稳定、长任务恢复和性能定位。
- `package.index.md`: 打包交付、依赖资源、构建环境、配置密钥、版本、验证、分发说明。
- `web-automation.index.md`: 浏览器自动化、登录态、等待、iframe、弹窗、取证、批量执行。

## 维护重点

- 是否先识别用户可见后果、数据破坏等级和交付风险。
- 是否避免把小工具做成重平台，也避免没有诊断、没有验证、没有回退。
- 是否把真实样本、真实路径、真实浏览器状态作为验证依据。
- 是否区分一次性任务、可重复工具、长期交付物。
