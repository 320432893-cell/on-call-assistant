# 专题索引: On-call Assistant 交付体检

本专题只处理项目结束后或用户明确声明后的交付体检。体检目标是用二八法则找出最影响交付、验收、复盘和长期运行的少数问题，并给出证据、取舍和下一步。

非体检、非审查、非复盘、非验收任务不启用本专题。

## 1. 体检总原则

每次读取本专题后，必须按以下方式执行：

1. 先识别交付风险面：用户路径、数据正确性、API 契约、部署运行、自动化副作用、诊断取证。
2. 再按 ROI 排序：优先检查收益高、事故概率高、修复代价低、能用证据确认的问题。
3. 只输出最关键的 1-3 个问题；其余低收益问题归入“暂不处理”。
4. 每个问题必须绑定证据：文件、页面、接口、字段、日志、截图、测试结果或真实样本。
5. 每个建议必须写清收益、代价、风险、适用边界和未验证项。

## 2. 体检输出格式

专题体检输出必须使用表格：

| 优先级 | 问题 | 证据 | 影响 | 推荐处理 | ROI / 取舍 | 未验证项 |
|---|---|---|---|---|---|---|
| P0/P1/P2 | 具体问题 | 文件 / 页面 / 接口 / 样本 / 测试 | 用户或交付后果 | 修复 / 补验证 / 暂不处理 | 收益、代价、风险、边界 | 需要补的证据 |

排序规则：

- P0: 会导致交付不可用、数据破坏、权限泄漏、批量误操作、无法恢复或无法定位。
- P1: 会明显影响验收、复盘、用户主路径、API 兼容、安装运行或长期维护。
- P2: 有改进价值，但短期不阻塞交付；只在成本很低或与 P0/P1 同路径时处理。

## 3. 体检入口

### 用户可见交互

读取 `interaction.index.md`:

- 按钮、弹窗、表单、窗口、菜单、快捷键。
- 加载、空状态、成功、失败、停止、重试、关闭。
- 日志、诊断、复制、导出、路径选择、文件拖拽。
- 用户明确要求交互、体验、验收、可用性或可排查性体检。

### On-call 架构入口

读取 `oncall-architecture.index.md`:

- 入口、核心逻辑、服务编排、适配层边界。
- source of truth、配置、secret、外部服务、回退策略。
- 多入口重复、临时脚本长期化、核心抽象失控。

### On-call API 契约

读取 `oncall-api.index.md`:

- FastAPI / Starlette / HTTP API 路由、请求、响应、状态码。
- 鉴权、权限、事务、后台任务、错误响应、可观测性。
- 后端接口会影响前端、外部调用方或内部服务调用。

### On-call Web 用户路径

读取 `oncall-web.index.md`:

- Web 页面、组件、状态、API 调用、异步生命周期。
- 图表、表格、统计口径、字段映射、前端安全。
- loading、empty、error、success 与真实数据生命周期一致性。

### On-call 操作台 UI

读取 `oncall-operator-ui.index.md`:

- 桌面 GUI、本地可视化工具、窗口、UI 线程、后台任务。
- 任务生命周期、状态一致性、关闭行为、错误恢复、诊断取证。

### 数据处理

读取 `data.index.md`:

- Excel / CSV / JSON / SQL / 接口数据读取、清洗、合并、转换、写出。
- 去重、关联、汇总、金额、时间、覆盖已有文件。
- 新数据源、字段结构不明确、数据会进入报告 / 模型 / 写库 / 自动决策。

### 打包交付

读取 `package.index.md`:

- exe、zip、Docker、Web 服务、CLI、HTML 展示页、演示稿。
- 依赖、资源、配置、版本、构建环境、运行环境、分发说明。
- 非开发机运行、客户现场、生产部署或正式交付。

### 浏览器自动化

读取 `web-automation.index.md`:

- Playwright / Selenium / RPA / 浏览器脚本。
- 登录态、验证码、iframe、弹窗、新 tab、下载上传。
- 批量抓取、批量提交、自动截图、失败取证、目标系统状态变更。
