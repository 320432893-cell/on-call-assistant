# 打包与交付规则索引

本文件只做打包交付路由。默认停在本文件，不自动读取 `package.details.md`。

## 1. 触发

- 打包、构建产物、分发、版本、配置、运行时依赖、交付验证。
- exe、zip、Docker、Web 服务、CLI、HTML 展示页、演示稿交付。
- 用户需要在非开发机运行或给其他用户使用。

## 2. 轻量试包

本机临时试包、给自己验证打包命令时，不默认读取 details。

最低要求:

- 说明这不是正式交付验证。
- 至少运行一次产物或等价入口。
- 不把“本机能跑”当成正式交付完成。

## 3. 读取 details

命中以下任一场景，读取 `package.details.md`:

- 正式交付、部署到测试 / 生产、客户现场或他人使用。
- 需要依赖、资源、动态加载、构建环境、配置、密钥、多环境。
- 需要版本、构建元数据、最小可用链路、分发清单、用户说明。
- 体积异常、运行时依赖、现场故障排查。
- 自动更新、安装器、服务注册、系统权限、数据迁移或不可逆副作用。

## 4. 路由

- GUI 运行体验读取 `../engineering/gui.md`。
- 浏览器自动化交付读取 `web-automation.index.md`。
- 数据迁移或覆盖读取 `data.index.md`。
