# 数据规则索引

本文件只做数据风险路由。默认停在本文件，不自动读取 `data.details.md`。

## 1. 轻量数据任务

命中以下场景时，只用本文件做轻量判断，不读取 `data.details.md`:

- 只读展示。
- 单文件解析。
- 不写回、不合并、不过滤关键数据。
- 不涉及金额、生产数据、覆盖已有文件或批量状态更新。

必须做:

- 读取真实样本。
- 明确关键字段。
- 说明明显脏数据如何处理。

## 2. 读取 details

命中以下任一场景，读取 `data.details.md`:

- 多文件合并、比对、join、去重、关联。
- 过滤、汇总、金额计算、单位换算。
- 写文件、写数据库、更新状态、覆盖已有 Excel / CSV / JSON。
- 接入新 Excel / CSV / JSON / 数据库表 / 接口返回，且结构可能变化。
- 处理脏数据、重复数据、缺失值、格式不一致。
- 长时间或大批量处理，需要检查点、失败清单或可恢复执行。
- 需要完整性对账、幂等写入、人工修改冲突处理。

读取边界:

- 不因为任务里出现“数据”二字就读取 details。
- details 只管数据正确性和数据事故防护，不替代后端、前端或交付规则。
- 读取 details 后，优先使用当前任务命中的章节，不全量套用。

## 3. 升级与阻断

以下情况必须停下说明风险，必要时等用户拍板:

- 未看真实样本就准备写解析或清洗逻辑。
- 写入、覆盖、删除、迁移数据但没有回滚路径。
- 关联键、时间、金额、单位或生产数据语义靠猜。
- 多步写入可能部分成功，但没有幂等或对账策略。

## 4. 下一步规则路由

- 数据来自或写入 HTTP API 时，按需读取 `../engineering/backend.index.md`。
- 数据用于前端图表、表格或统计展示时，按需读取 `../engineering/frontend.index.md`。
- 数据处理结果要交付给用户、部署或分发时，按需读取 `package.index.md`。
