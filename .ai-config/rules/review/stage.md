# 阶段体检（顶层·深而按扰动面 scope；枢纽见 review.index.md）

触发：**人**在切片闭包 / 交接前 / 合 main 前 / 要动大东西前贴本路径。范围 = 切片 diff 或 `main...HEAD`。
目标：守 L1–L3(工具够不到的架构层);过了才合 main。

## 第一步·扰动侦测(决定审哪层,确定性·从 diff 算·不靠察觉)
跑 `git diff <范围>` → AST 分类,得待审面:
- 新模块 / 新跨包 import → **L1**;
- 新顶层 def/class(dup-symbol 近名)/ 新模块覆盖既有能力 → **L2**;
- 公共函数签名/返回变 / 碰 save·batch·幂等 路径 → **L3**;
- 新增 抽象(继承 ABC / 注册分发字典 / 新包装层)→ **§1 证据闸**(索要三点)。

**测试脚本/文档/局部 bugfix → 四类全空 → 不触发深审,只走 daily 那套。审查量=扰动量。**

## 第二步·按亮起的面 scope 审(子agent对抗,只喂待审面)
- **L1 依赖**:import 图新增边/方向违规;**人定契约本身对不对**(不只验守不守)。
- **L2 双源/归属**:def/class 名近似聚类+签名+扇入叉乘(近名+一死=删候选);**不同名的语义双源 → 派 finder→refuter 对抗 workflow**(本轮那种,只喂 scope);入口是否真薄(业务逻辑混进 tools 入口)。
- **L3 契约/不变量**:schema-diff 公共符号;碰写入/批量/幂等 → **要/验 §3 真测试**(幂等连调2次副作用=1、部分成功注入第N+1条失败可区分、返回结构可判别)。
- **设计/语义味道**(工具判不了,只此处审):§1 新抽象有没有三点证据 / §2 抓手用对没·过度没 / 命名表不表业务意图 / 重复**业务**逻辑。
- **承重**:改动模块按 fan-in 排序,高扇入重点审。

## 第三步·对抗证伪 + 逐条交(宁可误杀)
每条发现配 refuter 反驳(默认存疑);四档结论:坐实 / 候选-未坐实 / 需运行时验证 / 推翻。**逐条交、一次一条**(禁一次性甩多条定级);坐实才动手,删码举证责任在发现方。

## 第四步·合 main
全过 + check.py deep 退0 + 子agent四档结论 + 死码/废弃清单(已删 或 放行登记:原因+可判定清除条件)→ 合 main。碎 WIP 历史在此 squash 一次给人看。

## `[强制产物]`
四档结论(逐条)+ 死码/双源/废弃清单 + 白名单/skip pending(待你批)+ 漂移快照 + 承重面清单。
