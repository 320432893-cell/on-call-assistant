# 阶段体检·执行(顶层;人触发;范围=切片 or main...HEAD)

## 1. 扰动侦测(git diff + AST 分类 → 待审面;确定性,不靠察觉)
- 新模块 / 新跨包 import → **L1**
- 新顶层 def·class(dup 近名)/ 新模块盖既有能力 → **L2**
- 公共签名·返回变 / 碰 save·batch·幂等 路径 → **L3**
- 新抽象(继承 ABC / 注册分发字典 / 新包装层)→ **§1 索三点证据**
四类全空(测试脚本/文档/局部 bugfix)→ 只跑 daily,不深审。审查量=扰动量。

## 2. 按亮面 scope 审(子agent对抗,只喂亮的面)
- **L1**:import 图新边/方向违规;人定契约本身对不对(不只验守不守)。
- **L2**:`check_cohesion` 判可拆否;def·class 名近似+签名+扇入叉乘(近名+一死=删候选);不同名语义双源→finder→refuter;入口是否真薄(业务逻辑混进 tools 入口)。
- **L3**:schema-diff 公共符号;碰写入/批量/幂等→要/验 §3 真测试(幂等连调2次副作用=1、部分成功注入第N+1条失败可区分、返回结构可判别)。
- **设计/语义味道**(工具判不了,仅此审):§1 新抽象有三点证据?§2 抓手用对/过度?命名表业务意图?重复业务逻辑?
- **承重**:改动模块按 fan-in 排序,高扇入重点。

## 3. 对抗证伪 + 逐条交(宁可误杀)
每条发现配 refuter 反驳(默认存疑)→ 四档:坐实 / 候选-未坐实 / 需运行时验证 / 推翻。逐条交、一次一条;坐实才动手,删码举证责任在发现方。

## 4. 合 main
全过 + `check.py deep` 退0 + 四档结论 + 死码/废弃清单(已删 or 放行登记:原因+可判定清除条件)→ 碎 WIP squash → 合。

`[强制产物]`:四档结论(逐条)+ 死码/双源/废弃清单 + 放行 pending(待人批)+ 漂移快照 + 承重清单。
