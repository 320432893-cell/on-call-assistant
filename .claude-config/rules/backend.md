# FastAPI 后端规则强制版

## 文件定位
- 本文件只包含**强制阻断级**规则，覆盖 FastAPI / Starlette 项目最高频高影响场景
- 强制规则数 ≤ 10 条（workflow.md § 2.3.2 上限）
- 跨文件职责分工：
  - 通用代码规范见 `code.md`
  - 分层架构见 `architecture.md`
  - 多环境配置 / 版本元数据见 `package.md`
  - 数据契约见 `data.md`

---

## 1. 路由与版本化【强制】

### 触发条件
新增/修改 HTTP 路由（@router.get / @router.post 等）

### 必须输出
```
[路由版本化自检]
- 路由路径：________________
- 版本前缀：□ /v1 □ /v2 □ 内部接口（无需版本）□ 公开接口无版本（阻断）
- 路由分组（router prefix）：________________
- 变更类型：□ 新增 □ 兼容修改 □ 破坏性变更
- 破坏性变更处理（删字段、改语义、改返回结构）：
  □ 升版本（/v1 → /v2，旧版本保留过渡期）
  □ 加新接口保留旧接口
  □ 仅内部用且通知所有调用方
- 路径风格统一：□ 全部 kebab-case 或 snake_case 统一 □ 混用（阻断）
```

### 阻断条件
- 公开路由无版本前缀 → **[阻断] 加 /v1 等版本前缀**
- 破坏性变更未升版本且未通知调用方 → **[阻断] 升版本或加兼容路由**
- 路径命名风格混用（kebab/snake/camel 同时存在）→ **[阻断] 统一一种风格**

## 2. 请求/响应模型契约【强制】

### 触发条件
新增/修改路由的请求体、响应体、查询参数

### 必须输出
```
[请求响应契约自检]
- 接口：________________
- 请求模型：
  □ 用 Pydantic BaseModel
  □ 用 dict / Any（阻断，除非明确"动态字段"且文档化）
  □ 字段有类型注解
  □ 字段有 Field(..., description=...) 或注释
- 响应模型：
  □ 用 response_model=XxxOut 显式声明
  □ 不直接返回 ORM 对象（用 from_attributes / 显式映射）
  □ 不返回 dict 让客户端"自己解析"
- 验证规则：
  □ 必填/可空字段明确
  □ 取值范围（min/max/regex）已声明
  □ 嵌套结构使用嵌套 Pydantic 模型
- 错误响应：
  □ HTTPException 用结构化 detail
  □ 错误响应也有模型（ErrorResponse）
```

### 阻断条件
- 请求体或响应体用 dict / Any → **[阻断] 用 Pydantic 模型**
- 路由无 response_model 声明 → **[阻断] 显式声明响应模型**
- 直接返回 ORM 对象给客户端 → **[阻断] 用响应模型映射，避免暴露内部字段**

## 3. 鉴权与权限边界【强制】

### 触发条件
新增路由

### 必须输出
```
[鉴权权限自检]
- 路由：________________
- 鉴权类型：□ 无需鉴权（明示原因：________）□ Token □ Session □ API Key □ 内部调用
- 权限分组：
  □ 路由按权限分组到不同 router（公开 / 用户 / 管理员）
  □ 不同权限路由混在同一 router（阻断）
- 鉴权实现：
  □ 通过 Depends(...) 注入鉴权依赖
  □ 在路由函数内手写鉴权代码（阻断）
- 用户身份获取：
  □ 通过 Depends 注入 current_user
  □ 从 request.state 或 header 直接读（说明：________）
- 资源所有权检查：
  □ 涉及操作他人数据的接口，已检查 user_id 与资源 owner_id 匹配
```

### 阻断条件
- 公开路由无明示"无需鉴权"声明 → **[阻断] 显式标注鉴权要求**
- 不同权限路由混在同一 router → **[阻断] 拆分到不同 router**
- 鉴权写在路由函数体内（不用 Depends）→ **[阻断] 改为依赖注入**
- 操作他人数据的接口无所有权检查 → **[阻断] 加 user_id == owner_id 校验**

## 4. 数据库事务边界【强制】

### 触发条件
- 新增数据库写操作（INSERT / UPDATE / DELETE）
- 多步 DB 操作（≥ 2 次写）

### 必须输出
```
[DB 事务边界自检]
- 操作位置：________________
- 写操作步骤：步骤 1 ____ → 步骤 2 ____ → ...
- 事务边界声明：
  □ 单步写：自动事务即可
  □ 多步写：用 async with session.begin() 或 transaction context
  □ 跨服务/跨方法：在编排层开事务，service 层接收 session
- 事务时长：
  □ 短事务（< 1 秒）：通过
  □ 长事务（含外部 IO / sleep）：拆分或异步化（阻断）
- 失败处理：
  □ 异常自动回滚
  □ 异常透传给调用方
  □ 不在事务内 commit 后又抛错
- 与 data.md § 8 失败模式的关系：
  □ 多步写已声明原子性边界 + 部分成功策略
```

### 阻断条件
- 多步写操作无事务声明 → **[阻断] 用事务上下文包裹**
- 事务内含外部 IO / 长 sleep → **[阻断] 拆短事务，外部 IO 放事务外**
- 跨请求持有事务（一个事务跨多个 HTTP 请求）→ **[阻断] 事务必须在单个请求内闭合**

## 5. 后台任务边界【强制】

### 触发条件
- 用 `BackgroundTasks` 添加任务
- 引入 Celery / RQ / arq 等任务队列
- async 协程脱离请求生命周期运行

> 失败可见性、异常吞错、并发选型 由 `code.md` § 6 并发安全 阻断；幂等性细节由 `data.md` § 2 幂等设计 阻断；本规则只管 FastAPI 上下文里"用什么跑后台任务"。

### 必须输出
```
[后台任务边界自检 - FastAPI 专项]
- 任务：________________
- 选型判定（必须明确选一项并填理由）：
  □ BackgroundTasks（< 5 秒、不重要、丢失可接受）
  □ Celery / RQ / arq（生产任务、需要重试 / 持久化 / 监控）
  □ asyncio.create_task（短时纯异步）
- 阻塞性检查：
  □ BackgroundTasks 不阻塞请求线程
  □ 同步阻塞操作放线程池（run_in_threadpool）
- 任务脱离请求生命周期：
  □ 已确认任务不依赖 request/response 对象
  □ 任务的依赖（DB session / context）独立创建，不复用请求级依赖
```

### 阻断条件
- BackgroundTasks 跑 ≥ 5 秒任务且重要 → **[阻断] 改用 Celery / RQ / arq**
- 后台任务复用请求级 DB session → **[阻断] 任务必须独立创建依赖**
- 选型理由空白（三个选项都没填理由） → **[阻断] 必须说明为什么选这个**

## 6. 可观测性最小集【强制】

### 触发条件
- **新建 FastAPI 项目骨架** / 项目首次接入 middleware
- 检查发现项目缺失 trace_id middleware 或全局错误日志
- 改动单个路由不触发本规则（HTTP 层观测属基础设施，一次性建立）

### 必须输出
```
[可观测性最小集自检]
- 请求 ID（trace_id）：
  □ middleware 自动生成（uuid / X-Request-ID）
  □ 透传到日志和下游服务调用
  □ 错误响应包含 trace_id 便于排查
- 慢请求日志：
  □ 请求耗时 > 阈值（默认 1 秒）自动记录 WARN
  □ 含路径 / 用户 / 耗时 / SQL 数（如可获取）
- 错误日志：
  □ 5xx 错误必记录（含完整 traceback）
  □ 4xx 错误按需记录（防刷日志）
  □ 日志关联 trace_id
- 业务指标（如适用）：
  □ 关键接口的成功率 / 错误率有可查询位置
- 与 code.md 可观测性的关系：
  □ 本规则是 HTTP 层补充，日志规范工具链(ruff T20/LOG)已查 print/root logger,本规则补 trace_id/慢请求/5xx 错误日志
```

### 阻断条件
- 路由处理无 trace_id 机制 → **[阻断] 加 middleware 生成并透传**
- 5xx 错误无日志 → **[阻断] 必须记录完整 traceback**
- 错误响应无任何排查标识 → **[阻断] 至少返回 trace_id**

## 附录A：推荐级规则（完成后复查）

以下规则不触发阻断，代码完成后自查；优先交给工具链。

### A.1 接口文档
- 路由 / 模型补全 description / examples
- OpenAPI 文档可访问（默认 /docs）
- 关键接口在文档里有调用示例

### A.2 限流与熔断
- 公开接口建议加限流（slowapi / 网关层）
- 调外部服务用 architecture.md § 7 外部服务调用边界（超时 / 重试 / 降级 / 熔断）

### A.3 异步与并发
- IO 密集路由用 async def
- 阻塞操作（同步 DB / 文件）放线程池
- 不在 async 函数中调阻塞 IO

### A.4 数据库迁移
- Schema 变更用迁移工具（Alembic）
- 迁移脚本入 git，PR 中明确说明
- 破坏性迁移有回滚脚本

### A.5 测试
- 路由有 pytest + httpx.AsyncClient 集成测试
- 鉴权 / 权限边界优先测试
- 关键业务流程有 E2E 用例
