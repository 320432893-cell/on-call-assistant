# 前端规则（Vue 3 + ECharts）强制版

## 文件定位
- 本文件只包含**强制阻断级**规则，推荐级规则移至附录
- 违反即阻断，无阻断条件的陈述句已删除
- 技术栈默认 Vue 3 + ECharts，其他栈以项目声明为准

---

## 1. 组件拆分规则【强制】

### 触发条件
新增/修改 Vue 组件，单文件行数可能超过 200 行

### 必须输出
```
[组件拆分自检]
- 当前文件行数：________
- 是否超过 200 行：□ 是 □ 否
- 若超过 200 行：
  □ 存在可复用展示单元 → 拆出子组件
  □ 存在逻辑超过 3 步的 computed → 拆出 composable
- 是否超过 300 行：□ 是 □ 否
- 若超过 300 行：□ 已无条件拆分
```

### 阻断条件
- 超过 300 行未拆分 → **[阻断] 组件过大（>300行），必须拆分子组件或 composable**
- 超过 200 行且存在可拆分单元未拆 → **[阻断] 存在可复用单元，建议拆分后继续**

## 2. API 封装规则【强制】

### 触发条件
新增后端接口调用

### 必须输出
```
[API 封装自检]
- 接口路径：________________
- 调用位置：□ API 层（通过） □ 组件内直接调用 fetch/axios（阻断）
- 封装文件路径：________________
- 前端字段名与后端 key 一致性：□ 是 □ 否，映射层位置：________
```

### 阻断条件
- 组件内直接调用 fetch/axios → **[阻断] 后端接口必须封装在独立 API 层，禁止组件内直接调用**
- 字段名不一致且无映射层 → **[阻断] 前端字段名必须与后端一致，不一致时需增加显式映射层**

## 3. 异步三态规则【强制】

### 触发条件
新增/修改异步数据加载（接口请求、数据获取）

### 必须输出
```
[异步三态自检]
- 数据源：________________
- loading 态处理：□ 有（组件：________） □ 无（阻断）
- error 态处理：□ 有（展示内容：________） □ 无（阻断）
- success 态处理：□ 有 □ 无（阻断）
- error 展示内容检查：
  □ 人类可读原因（非接口报错原文）
  □ 无技术栈信息暴露
```

### 阻断条件
- 缺少 loading 态 → **[阻断] 异步加载必须处理 loading 态**
- 缺少 error 态 → **[阻断] 异步加载必须处理 error 态**
- 缺少 success 态 → **[阻断] 异步加载必须处理 success 态**
- error 展示接口报错原文或技术栈 → **[阻断] 错误信息必须转换为人类可读文案，禁止暴露技术细节**

## 4. 图表数据规则【强制】

### 触发条件
新增/修改 ECharts 图表组件

### 必须输出
```
[图表数据自检]
- 图表类型：________________
- 数据字段验证：
  □ x 轴字段存在于数据中
  □ y 轴字段存在于数据中
- 数据量：________ 条
- 数据量处理：
  □ ≤ 1000：保留完整 tooltip、动画、高亮
  □ > 1000：简化 tooltip、禁用动画、采样显示
- 多时间点 x 轴：
  □ 已做间隔采样（数据点 > 50 时按 Math.ceil(dataLength / 50) 控制）
  □ 不适用
- 空数据处理：
  □ option 在数据为空时返回 { series: [] }
  □ 或：数据为空时不渲染图表并展示占位提示
- 异常数据检测：
  □ 全为 0 → 已说明原因
  □ 全部相同 → 已说明原因
  □ 缺失率 > 80% → 已说明原因
  □ 无时间/分类维度 → 已说明原因
  □ 以上均无
```

### 阻断条件
- x/y 轴字段未验证存在性 → **[阻断] 请确认字段确实存在于数据中**
- 数据量 > 1000 未做性能处理 → **[阻断] 大数据量图表需简化 tooltip、禁用动画或采样显示**
- 异常数据勾选项未说明原因 → **[阻断] 图表数据异常，请说明处理方式或原因后继续**

## 5. 技术字段屏蔽规则【强制】

### 触发条件
新增/修改面向用户的展示内容（模板、文案、提示）

### 必须输出
```
[技术字段屏蔽自检]
- 检查项：
  □ 无代码片段展示
  □ 无技术字段名（如 name_id、created_at）
  □ 无接口路径
  □ 无 SQL 表名
  □ 无原始报错信息
  □ 无技术栈信息（stack trace 等）
- 若存在技术术语需展示：
  □ 已转换为业务语言（如：created_at → 创建时间）
```

### 阻断条件
- 任一检查项未勾选 → **[阻断] 面向用户界面禁止暴露技术细节，请转换为业务语言**

## 7. 空数据兜底规则【强制】

### 触发条件
新增/修改数据展示区域（表格、列表、卡片、统计数字等）

### 必须输出
```
[空数据兜底自检]
- 数据为空时处理：
  □ 展示占位提示（文案：________）
  □ 隐藏该模块（已说明原因：________）
  □ 展示默认值（值：________）
- 字段缺失时处理：
  □ 有兜底展示
  □ 不渲染该字段
- null 值调用检查：
  □ 模板中对可能为 null 的值使用可选链或有回退值
```

### 阻断条件
- 数据为空无任何处理说明 → **[阻断] 请说明数据为空时的展示策略**
- 模板中直接对可能为 null 的值调用方法（如 .toFixed()）→ **[阻断] 请使用可选链或提供回退值**

## 8. 状态管理边界规则【强制】

### 触发条件
- 新增 state（ref / reactive / computed）
- 跨组件传递数据
- 引入 Pinia / Vuex store

### 必须输出
```
[状态管理边界自检]
- 数据：________________
- 归属判定（只能选一个）：
  □ 组件本地 state：仅当前组件使用
  □ Props 上提：父子组件共用，由父级持有
  □ Store（Pinia 等）：跨页面 / 跨组件树 / 全局状态
  □ Router / URL query：可分享 / 可回退的状态
- 权威源声明：这份数据的唯一权威源是：________________
- 修改路径：哪些地方可以修改这份数据：________________
- 反模式检查：
  □ 无跨组件复制 state（A 组件 copy B 组件的 state）
  □ 无既改 prop 又改本地 state
  □ Store 数据不在组件内重新做 reactive 包装
```

### 阻断条件
- 同一份数据有 ≥ 2 个权威源 → **[阻断] 同一份数据只能有一个权威源**
- 跨组件复制 state（A 组件持有 B 组件 state 的副本）→ **[阻断] 改为 props 上提或 store**
- 子组件直接修改 prop → **[阻断] 通过 emit 让父级修改**

## 9. 错误边界规则【强制】

### 触发条件
- 新增关键业务模块（数据加载组件 / 图表 / 子页面 / 表单提交流程）
- 新增异步加载 / 第三方组件包装

### 必须输出
```
[错误边界自检]
- 关键模块：________________
- 错误边界覆盖（Vue: errorCaptured / React: ErrorBoundary）：
  □ 该模块外层有错误边界
  □ 边界粒度：□ 模块级 □ 子页面级 □ 仅根级（阻断）
- 边界行为：
  □ 单组件 crash 不拖死整页
  □ 错误显示对用户友好（参考 § 3 异步三态 error 展示要求）
  □ 错误自动上报（日志 / 监控）
- 异步异常：
  □ Promise rejection 已处理（catch / try-await）
  □ window.onerror / unhandledrejection 全局监听
```

### 阻断条件
- 关键业务区无错误边界，仅根级 ErrorBoundary → **[阻断] 关键模块需独立边界，防止整页崩溃**
- 异步操作无 catch → **[阻断] Promise rejection 必须处理**

## 附录A：推荐级规则（完成后复查）

以下规则不触发阻断，代码完成后自查：

- **组件命名**：PascalCase、文件名与组件名一致、页面级以 View/Page 结尾
- **类型声明**：props 必须声明类型（禁止裸 Object/any）、emit 必须声明参数类型
- **文案业务化**：数据来源说明用业务语言、评分体系展示评估标准表
- **对比分析**：同业对比样本量 < 3 时改为纵向趋势分析
- **单位统一**：跨表计算显式注明单位换算
