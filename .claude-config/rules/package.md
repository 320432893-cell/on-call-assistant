# 打包与交付规则强制版

## 文件定位
- 本文件只包含**强制阻断级**规则，覆盖 PyInstaller 打包、依赖管理、交付验证
- 违反即阻断，无阻断条件的陈述句已删除

---

## 1. 依赖完整性规则【强制】

### 触发条件
开始打包前（执行 PyInstaller 或构建交付物）

### 必须输出
```
[依赖完整性自检]
- 步骤1：收集所有 requirements.txt
  □ 主项目 requirements.txt
  □ 子项目 requirements.txt（列表：________________）
  □ 动态加载模块的 requirements.txt（列表：________________）

- 步骤2：分析动态加载
  □ Grep搜索 `importlib`|`spec_from_file_location`|`__import__`
  □ Grep搜索 `sys.path.insert`|`sys.path.append`
  □ 动态加载目录确认：________________

- 步骤3：合并依赖清单
  | 包名 | 来源 | 版本 |
  |------|------|------|
  |      |      |      |

- 步骤4：打包环境验证
  □ 在打包环境安装所有依赖
  □ 在打包环境运行一次程序，所有import成功
  □ 专用打包环境（非日常开发环境）

- 步骤5：打包后测试
  □ 打包完成立即运行exe
  □ 测试动态加载模块功能
```

### 阻断条件
- 步骤1-5任一未完成 → **[阻断] 依赖完整性检查未完成，请补全步骤 [X]**
- 动态加载模块依赖未收集 → **[阻断] 发现动态加载，但未收集其子项目依赖**
- 打包环境非专用 → **[阻断] 必须使用专用打包环境，禁止复用开发环境**
- 打包后未运行测试 → **[阻断] 打包后必须运行exe并测试动态加载功能**

## 2. 体积检查规则【强制】

### 触发条件
打包完成后

### 必须输出
```
[体积检查自检]
- 产物总大小：________ MB
- _internal目录大小：________ MB
- 最大子目录排名：
  1. ________（________ MB）
  2. ________（________ MB）
  3. ________（________ MB）
- 体积评估：□ 正常 □ 异常（说明：________）
- 异常排查（若异常）：
  □ 环境污染 □ hook误收集 □ 实验依赖混入 □ 可选依赖未排除
```

### 阻断条件
- 未核对产物大小 → **[阻断] 请核对产物总大小和_internal大小**
- 体积异常未排查原因 → **[阻断] 体积异常，请排查原因后继续**

## 3. 最小可用链路验证规则【强制】

### 触发条件
打包完成，准备交付前

### 必须输出
```
[最小可用链路自检]
- 程序类型：□ 桌面程序 □ Web应用 □ 其他
- 桌面程序验证：
  □ 主窗口可打开
  □ 核心操作可执行
  □ 资源文件加载正常
  □ 退出流程正常
- Web应用验证：
  □ 根路径 `/` 可访问
  □ `/api/health` 正常
  □ 关键API正常
  □ 主要静态资源正常
- 验证结果：□ 通过 □ 未通过（问题：________）
```

### 阻断条件
- 桌面程序任一项未通过 → **[阻断] 桌面程序最小链路验证未通过，请修复后再交付**
- Web应用任一项未通过 → **[阻断] Web应用最小链路验证未通过，请修复后再交付**
- 未实际完成验证 → **[阻断] 未完成最小可用链路验证，不得视为交付完成**

## 4. 分发清单规则【强制】

### 触发条件
打包完成，准备分发给其他用户时

### 必须输出
```
[分发清单自检]
- 分发文件：
  □ 整个 `dist/<项目名>/` 文件夹
  □ 已压缩为zip
  □ exe与_internal在同一目录（禁止单独移动exe）

- 运行时外部依赖：
  □ Chrome/Edge浏览器 □ 数据库客户端 □ 其他：________
  □ Playwright浏览器需单独安装 □ VC++运行库 □ 其他运行时

- 需用户修改的配置：
  | 配置文件 | 字段 | 说明 | 必填 |
  |----------|------|------|------|
  |          |      |      |      |

- 运行时生成目录：
  □ output目录（自动生成/需提前创建）
  □ logs目录（自动生成/需提前创建）
  □ 缓存目录（自动生成/需提前创建）

- 使用说明.txt：□ 已生成 □ 未生成（阻断）
  - 包含：启动方式、外部依赖、需修改配置、常见问题
```

### 阻断条件
- 单独分发exe（无_internal）→ **[阻断] PyInstaller目录版必须连同_internal一起分发，禁止单独发exe**
- 使用说明.txt未生成 → **[阻断] 分发前必须生成使用说明.txt**
- 运行时依赖未列出 → **[阻断] 请列明运行时外部依赖**
- 需修改配置未说明 → **[阻断] 请说明用户需修改的配置文件及字段**

## 5. 多环境构建规则【强制】

### 触发条件
- 同一项目需要在 ≥ 2 个环境（dev / test / staging / prod）运行
- 打包前的配置组织

### 必须输出
```
[多环境构建自检]
- 目标环境：□ dev □ test □ staging □ prod
- 配置外置（参考 architecture.md § 5）：
  □ 各环境差异通过 .env / .env.{env} / 配置文件
  □ 启动时通过环境变量或命令行参数指定环境
  □ 产物内部不包含任何特定环境的密钥/URL
- 密钥隔离：
  □ prod 密钥不在 dev/test 配置中
  □ 各环境密钥独立轮换
  □ 产物本身不内置任何密钥
- 环境切换方式：
  □ 改启动参数 / 环境变量即可切换
  □ 需修改代码后重打包（阻断）
- 同一份产物多环境能力：
  □ 是（推荐）：一次构建 → 多环境部署，靠配置区分
  □ 否：每个环境独立构建 → 需说明理由
```

### 阻断条件
- 产物内包含 prod 密钥/URL/账号 → **[阻断] 移到环境变量或运行时注入**
- 切换环境需修改代码后重打包 → **[阻断] 改为配置驱动**
- 各环境密钥共用 → **[阻断] 至少 prod 必须独立**

## 6. 版本与构建元数据规则【强制】

### 触发条件
打包构建产物前

### 必须输出
```
[版本元数据自检]
- 版本信息内容：
  □ 版本号（语义化版本 / Date+Build / 其他：________）
  □ Git commit hash（短 SHA）：________
  □ 构建时间（ISO 格式）：________
  □ 构建环境标记（dev / test / prod）：________
  □ 构建者标识（CI / 用户名）：________
- 注入方式：
  □ 构建脚本读取 git rev-parse 注入到代码常量
  □ 写入 VERSION 文件随产物分发
  □ 嵌入到 exe 元数据 / Web 服务的 /version 接口
- 运行时可见性：
  □ CLI 程序：--version 参数可输出
  □ Web 服务：/version 或 /health 接口包含
  □ GUI：关于对话框 / 标题栏显示
- 字符串硬编码检查：□ 版本号非硬编码字符串 □ 硬编码（阻断）
```

### 阻断条件
- 产物无 git commit hash → **[阻断] 必须可追溯到具体 commit**
- 产物无构建时间或环境标记 → **[阻断] 必须可识别产物来源**
- 版本号是硬编码字符串（不随构建变化）→ **[阻断] 从 git tag / 构建时间生成**
- 运行时无任何方式查看版本 → **[阻断] 提供 --version / /version / 关于对话框**

## 附录A：依赖完整性执行细节

### 错误示例 vs 正确做法
```
# 错误做法
只看了 采购对账桌面版/requirements.txt，安装 PySide6 和 pandas，开始打包
结果：运行时 ModuleNotFoundError: 'playwright'

# 正确做法
1. Grep "importlib|spec_from_file_location" 找到动态加载
2. Read safe-payer-scraper/requirements.txt 发现 playwright, rapidfuzz
3. 合并依赖清单：PySide6, pandas, playwright, rapidfuzz
4. 在打包环境安装并运行验证
5. 打包并测试
```

### 动态加载检查命令
```bash
# 搜索动态加载
grep -r "importlib\|spec_from_file_location\|__import__" --include="*.py"
grep -r "sys.path.insert\|sys.path.append" --include="*.py"
```

## 附录B：推荐级规则（完成后复查）

- **环境隔离**：打包环境专用，与开发环境分离
- **资源声明**：静态资源、模板、配置文件逐项确认是否分发
- **运行时文件**：缓存、日志、临时文件不得预打入产物
- **打包问题处理**：优先通过入口整理/依赖裁剪/spec调整解决，不顺带重构业务代码
