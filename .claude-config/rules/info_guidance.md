# 信息引导漏斗协议

## 文件定位
- **按需加载**:仅当 AI 在"信息缺口"场景需要从用户拿信息时读
- 本协议规定:**当 AI 缺少决策所需信息时,必须按 5 步漏斗顺序穷尽,不得跳级**
- 配套 `risk_reasoning.md`(风险识别)

---

## 0. 总原则

- AI 是**主导方**,负责知道"该问什么"和"怎么拿"
- 用户**必然知道业务信息**(做什么 / 谁用 / 怎么用),工程信息可不知道
- 缺工程信息时,AI 必须按漏斗 1→5 顺序尝试,**不得直接跳到第 5 步"行业典型假设"**
- 终极目标:对架构决策有用的关键信息**全部到位**

---

## 1. 漏斗 5 步(必须按顺序)

### 第 1 步:AI 自取(免问用户)
AI 能自己拿到的信息,直接拿,不问用户。手段:
- **WebFetch**:第三方 API 文档 / 公开站点说明 / GitHub README
- **只读 shell 命令**:`df -h` / `free -h` / `pip list` / `git log` / `python --version` / 文件大小 / 目录结构
- **Grep / Read**:读项目代码自己分析
- **Glob**:看文件分布

**触发**:任何"环境/版本/已有代码"类信息缺口
**授权**:已得到用户事前授权,不每次问

### 第 2 步:用户零成本提供
让用户做"30 秒能完成"的动作:
- "把这段日志/报错复制给我"
- "给我那个 URL"
- "截个屏"
- "粘贴一下你那个文件的前 20 行"

**触发**:第 1 步拿不到,但用户手边就有的具体物料

### 第 3 步:用户中成本取证(手动)
让用户花 5-15 分钟做:
- F12 开发者工具具体步骤(指令 ≤ 3 步)
- 打开某个文档/系统记录某个数字
- 跟业务方/相关方确认某事
- 实际跑一次现有流程观察

**触发**:第 2 步拿不到,需要用户主动取证
**注**:不写自动探测脚本(用户已明确不需要)

### 第 4 步:AI 给行业典型 + 用户复核
对"工程参数类"信息(QPS / 内存 / 超时阈值 / 重试次数 / 限流值),AI 主动给"典型值"让用户复核:

```
"我按 [项目类型] 的行业典型设:
  超时:30 秒
  重试:3 次,指数退避
  限流:100 QPS
  内存上限:512MB
你这个项目跟典型不一样的话告诉我"
```

**触发**:用户答不上"具体数字",但有行业共识可参考
**关键**:必须**显式标注**"这是我替你假设的",不是"已确认"

### 第 5 步:延后 + 标记假设
真无法获取且不影响地基决策的:
- 写入"待验证假设清单"
- 代码相关位置加注释 `# ASSUMPTION: 用户未明确,假设 X`
- 跑起来不对回头查

**触发**:1-4 步都试过仍无法确认
**禁止**:跳过 1-4 直接到 5

---

## 2. 业务信息(用户必然知道)的特殊处理

业务信息(项目做什么 / 谁用 / 业务流程 / 业务规则)**不走漏斗**——直接问用户。

**判定标准**:这件事用户大脑里有,不是工程参数。
- "你这个系统给谁用?"  → 业务,直接问
- "并发数多少?"          → 工程,走漏斗

**用户讲不清业务**:不是信息缺口问题,是用户**还没想清楚**。AI 必须停止技术讨论,反过来帮用户**梳理需求本身**。

---

## 3. 反模式(违反即视为协议失效)

- ❌ 直接跳到第 5 步给假设,不试 1-4 步
- ❌ AI 给假设不标注"我假设的"
- ❌ 业务信息也走漏斗(应直接问用户)
- ❌ 工程信息直接问用户填数字(应走漏斗)
- ❌ 第 4 步给典型值不让用户复核

---

## 4. 与紧急通道的关系

用户显式声明"急,跳过深挖,我自己负责" → 进入快速通道:
- 漏斗 1-3 步全跳
- 直接走第 4 步行业典型
- 但第 5 步假设清单**仍必须列出**,且 AI 在汇报中明确"本次走快速通道,以下为未验证假设"

---

## 5. 输出格式(信息缺口时给用户看的)

```
[信息缺口报告]

— 当前需要的关键信息 —
1. 信息 A(用于决策 X)
2. 信息 B(用于决策 Y)

— 我已经自取的(漏斗 1)—
- 信息 ____:从 ____(WebFetch/grep/...) 得到 = ____

— 需要你提供的零成本信息(漏斗 2)—
- 请粘贴 ____
- 请告诉我 ____

— 需要你取证的(漏斗 3,可选)—
- 步骤 1. ____
- 步骤 2. ____
- 步骤 3. ____
- 我用这个信息来决定 ____

— 我替你假设的(漏斗 4,需复核)—
- 假设 1:____ (来源:行业典型 / 类似项目)
- 假设 2:____

— 真无法确定的(漏斗 5,延后)—
- 假设 ____,跑起来如何验证:____
```
