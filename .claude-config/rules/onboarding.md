# 项目接手

## 文件定位
- **按需加载**:首次接触项目、新模块、或用户要求"接手"时读
- 接手目标是**理解项目**(地图测绘 + 关键文件通读判断),不是改项目
- 配套机制:`docs/PROJECT_PLAN.md` 是接手产物,下次直接读跳过本流程
- 接手完成后,新增功能/新模块走 `flow_new_project.md`;改老代码/修 bug/重构走 `flow_legacy_project.md`

---

## 0. 触发条件
- 首次接触新项目目录或新模块
- 用户明确说"接手"、"理解一下"、"先熟悉熟悉"
- 切换到陌生工作目录,需要建立心智模型才能动手

**不触发**:
- 纯文档阅读、一次性脚本(无后续改动意图)
- 已有 `docs/PROJECT_PLAN.md` 且未过期 → 直接读取,跳过本流程

---

## 1. 前置:开局体检

执行本流程前必须先完成 [workflow.md](workflow.md) § 1.1 开局体检(仓库根 / .gitignore / 暂存区 / 密钥 / 工具链)。

**基础设施异常未处理时不得开始接手流程。**

---

## 2. 核心步骤(4 步)

### 步骤 1: 地图测绘(机械, 客观, 不糊弄)

只跑命令,**不下任何判断**。

```bash
find . -name "*.py" -not -path "*/.*" -not -path "*/node_modules/*" | xargs wc -l 2>/dev/null | tail -1
find . -name "*.py" -not -path "*/.*" -not -path "*/node_modules/*" | wc -l
```

输出格式:
```
[地图测绘]
- 总行数: ____ 行
- .py 文件数: ____ 个
- 项目入口(grep "__main__" / FastAPI app / class 暴露): ____
- top 5 最长文件 (wc -l 排序): ____
- 依赖列表 (按出现频次 grep "^from" / "^import"): ____
```

### 步骤 2: AI 主动决定通读 / 不通读

基于地图测绘结果,AI **显式声明**决定:

```
[接手决定]
- 项目规模: ____ 行 / ____ 文件
- 我的决定: □ 通读(项目较小,通读可行) □ 不通读(项目较大,只做测绘 + 用户口述雷区)
- 理由: ____
- 请用户确认或反驳: ____
```

> **用户拍板规则**:用户可反驳(如"5000 行,我希望你通读"),AI 必须服从。

### 步骤 3: 按决定执行

| 决定 | 动作 | PROJECT_PLAN.md 完整度 |
|------|------|----------------------|
| **通读** | 通读入口 + 全部源文件 → 自己产出 PROJECT_PLAN.md 完整版 + 主动报反模式作为雷区候选(用户拍板) | 完整(项目本质 / 入口 / 调用链 / 分层 / 状态机 / 雷区清单) |
| **不通读** | 只填客观事实(入口 / 行数排名 / 依赖) → 雷区 100% 用户口述,AI 不评价 | 简版(入口列表 / 行数排名 / 依赖频次 / 用户口述雷区) |

### 步骤 4: 主动问用户 3 个口述问题

无论通读与否,**必须**问:
- 哪些地方你早就知道是雷区,改的时候要小心?
- 哪些地方是别人写的,你也不太懂?
- 上次改它出过什么问题?

用户回答 → 进雷区清单。

## 4. 阻断条件

- 未完成接手 4 步直接改代码 → **[阻断] 易出现调用链断裂、幽灵引用、状态不一致**
- 基础设施异常未报告就开始接手 → **[阻断] 先跑 workflow.md § 1.1 开局体检**
- `docs/PROJECT_PLAN.md` 与代码现状已不一致 → **[阻断] 先更新文档,不能基于过期心智模型动手**
- AI 自行决定通读/不通读但未显式声明给用户 → **[阻断] 步骤 2 必须显式,用户可反驳**

---

## 5. 与流程层文件的衔接

接手完成后:
- **新增功能/新模块,涉及架构决策** → 走 `flow_new_project.md`
- **改老代码 / 修 bug / 重构** → 走 `flow_legacy_project.md`(其门 3 必读雷区清单,命中则按既定决策,不重复问)

---

## 6. 反模式

- ❌ 跳过地图测绘直接通读 → 大项目 AI 通读 = 必糊弄
- ❌ AI 自行通读不报告 → 用户失去拍板权
- ❌ AI 主动评价老代码"是屎山"→ 应"雷区"中性词 + 用户口述
- ❌ 接手中发现基础设施异常不汇报,蒙头继续
- ❌ 不写 `docs/PROJECT_PLAN.md`,下次接手又重做一遍
