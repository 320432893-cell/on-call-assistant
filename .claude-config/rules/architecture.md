# 脚本转应用架构规则强制版

## 文件定位
- 本文件只包含**强制阻断级**规则，覆盖分层架构、依赖方向、引擎纯净、公共复用
- 违反即阻断，无阻断条件的陈述句已删除
- 通用编码规范以 `code.md` 为准，GUI 规则以 `gui.md` 为准

---

## 1. 脚本体检规则【强制】

### 触发条件
首次对某个脚本执行"封装"操作（加界面、转 Web、转应用）

### 必须输出
```
[脚本体检报告]
- 目标脚本：________________
- 体检项：

| 检查项 | 当前状态 | 是否需要先处理 |
|--------|---------|---------------|
| 核心处理函数纯净（无IO、无GUI回调、无print） | □ 是 □ 否 | □ 是 □ 否 |
| 多入口重复流程（如main和run重复编排） | □ 无 □ 有 | □ 是 □ 否 |
| 硬编码路径/配置在函数体内 | □ 无 □ 有 | □ 是 □ 否 |
| 单文件超过500行 | □ 否 □ 是（____行） | □ 是 □ 否 |

- 需先处理项：________________
- 建议：________________
```

### 阻断条件
无。体检报告提交用户确认，用户说"可以开始"后继续。

## 2. 分层依赖规则【强制】

### 触发条件
- 新增/修改跨层调用代码（页面→服务→引擎）
- 修改引擎层/核心函数的签名或行为（DIP 上层联动检查）

### 必须输出
```
[分层依赖自检]
- 修改位置：________________
- 依赖方向检查：
  □ 页面层 → 服务层（✓）
  □ 服务层 → 引擎层（✓）
  □ 引擎层 → 服务层（✗ 阻断）
  □ 页面层 → 引擎层（✗ 阻断）
  □ 公共层 → 业务模块（✗ 阻断）
- 依赖关系：□ 符合单向 □ 存在反向

—— 引擎层/核心函数变更时补充（DIP）——
- 修改函数：________________
- 上层依赖检查：
  □ 修改是否破坏服务层/页面层契约 □ 是 □ 否
  □ 上层是否需要同步修改 □ 是 □ 否
  □ 若是，调用方修改清单：________________
- 抽象边界：
  □ 引擎层签名变更通过抽象/Protocol 隔离 □ 直接暴露具体类型
```

### 阻断条件
- 引擎层依赖服务层/页面层 → **[阻断] 引擎层禁止依赖上层，必须可独立运行**
- 页面层直接import引擎层 → **[阻断] 页面必须通过服务层调用引擎，禁止直接依赖**
- 公共层依赖业务模块 → **[阻断] 公共层不得依赖业务模块，必须纯净**
- 修改引擎层导致上层联动且未列调用方清单 → **[阻断] 列出全部受影响的上层调用方再继续**

## 3. 引擎纯净规则【强制】

### 触发条件
新建或修改引擎层代码

### 必须输出
```
[引擎纯净自检]
- 引擎文件：________________
- 禁止项检查：
  □ 无import UI框架（PySide6/Qt/Flask/FastAPI/React相关）
  □ 无GUI对象参数（QWidget/QThread/Signal等）
  □ 无print()作为正式输出
  □ 无框架回调参数
- 独立运行验证：
  □ 可通过`python -c "from engine import process; process(data)"`独立调用
- 编排入口检查：
  □ CLI入口和GUI入口共用同一编排函数 □ 单入口 □ 多入口需合并
```

### 阻断条件
- import UI框架 → **[阻断] 引擎层禁止import任何UI框架**
- 接收GUI对象参数 → **[阻断] 引擎层禁止接收GUI对象**
- 使用print作为正式输出 → **[阻断] 引擎层使用logging，print仅调试用**
- 不能独立调用 → **[阻断] 引擎函数必须能脱离UI独立运行和测试**
- CLI和GUI入口不共用编排函数 → **[阻断] 同一业务流程禁止多入口重复编排，必须合并**

## 4. 公共复用规则【强制】

### 触发条件
新增页面功能、或在页面中实现某个功能

### 必须输出
```
[公共复用自检]
- 功能描述：________________
- 公共层检查：
  □ 已检查公共层现有组件
  □ 公共层已有类似功能（复用/扩展） □ 公共层无此功能（新建）
- 跨文件重复检查（Grep确认）：
  □ 该功能已在另一文件出现（第2次出现）→ 必须提取到公共层
  □ 首次出现 → 可保留在页面层
- 新建公共组件检查：
  □ 与已有组件无功能重叠（重叠则合并）
```

### 阻断条件
- 跨文件第2次出现未提取到公共层 → **[阻断] 跨文件第2次出现的逻辑必须立即提取到公共层**
- 页面层重新实现公共层已有功能 → **[阻断] 禁止页面层重复实现公共层功能，请复用**
- 新建公共组件与已有组件重叠 → **[阻断] 公共组件功能重叠，请合并而非新增平行实现**

## 5. 配置 vs 代码边界【强制】

### 触发条件
- 新增配置文件 / 环境变量 / 配置项
- 新增代码中的环境差异分支（dev / test / prod）
- 新增密钥、URL、阈值类的值

### 必须输出
```
[配置/代码边界自检]
- 新增内容：________________
- 归属判定：
  □ 走配置（外置）：阈值 / 路径 / URL / 密钥 / 环境差异值 / 第三方账号
  □ 走代码：状态机 / 算法 / 业务规则 / 流程编排
- 环境切换方式：
  □ 通过环境变量（推荐）
  □ 通过配置文件（.env / .toml / .yaml）
  □ 通过启动参数
  □ 通过代码 if env == 'prod' 分支（阻断）
- 密钥处理：
  □ 不在代码中硬编码
  □ 不进 git（在 .gitignore 中）
  □ 有 .env.example 模板（仅占位符）
```

### 阻断条件
- 业务逻辑里出现 `if env == 'prod'` 分支 → **[阻断] 环境差异走配置不走代码分支**
- 密钥/Token/APIKey 硬编码在代码中 → **[阻断] 移到环境变量或配置文件**
- 同一份阈值/URL 在多文件硬编码 → **[阻断] 提取到统一配置**

> 函数体内的硬编码细节(业务阈值、字段名、payload key)由 ruff PLR2004(配置在 ~/.ruff.toml)阻断,不在此重复。

## 6. 入口职责规则【强制】

### 触发条件
新增/修改入口函数：`main()` / CLI 入口 / FastAPI app 创建 / GUI entry / 服务启动函数

### 必须输出
```
[入口职责自检]
- 入口类型：□ CLI main □ FastAPI app □ GUI entry □ Service entry
- 入口函数行数：________ 行
- 入口职责清单（只允许做这三类事）：
  □ 参数解析 / 配置加载
  □ 依赖装配（DB 连接 / 服务实例化 / 路由注册）
  □ 启动（uvicorn.run / app.exec / cli.run）
- 禁止项检查：
  □ 入口内无业务逻辑分支
  □ 入口内无数据处理
  □ 入口内无算法实现
- 业务逻辑去向：调用哪个服务/编排函数：________________
```

### 阻断条件
- 入口函数 > 50 行 → **[阻断] 入口臃肿，把业务逻辑下移到服务层**
- 入口内含业务条件分支（非配置分支）→ **[阻断] 业务逻辑下移**
- 入口内直接做数据处理/算法 → **[阻断] 调用服务层而非内嵌**

## 7. 外部服务调用边界【强制】

### 触发条件
- 调用外部 HTTP API / 第三方 SDK / 跨服务 RPC
- 新增/修改重试、降级、熔断逻辑

### 必须输出
```
[外部调用边界自检]
- 调用目标：________________
- 超时：□ 已设置（值：________ 秒）□ 未设置（阻断）
- 重试：□ 有上限（次数：________）□ 无上限（阻断）□ 不适用
- 降级策略：□ 失败后兜底（说明：________）□ 透传错误
- 熔断：□ 连续失败 N 次后暂停（N=____）□ 不需要
- 幂等性：□ 重试安全（GET/带去重键）□ 不安全（需去重键，参考 data.md § 2）
```

### 阻断条件
- 外部调用无超时 → **[阻断] 必须设置超时**
- 外部调用无限重试 → **[阻断] 必须设置上限**
- 不幂等操作直接重试 → **[阻断] 加去重键或改幂等设计**

> 文件/数据库等本地资源生命周期由 `code.md` 资源管理 阻断；本规则只覆盖外部服务调用。

## 附录A：分层架构参考

### 四层模型映射

| 通用层 | 桌面(PySide6) | Web |
|--------|--------------|-----|
| 引擎层 | 独立Python模块，`if __name__=="__main__"`可直跑 | 同上，与桌面共用 |
| 服务层 | service.py，TaskThread+信号连接 | FastAPI/Flask路由层 |
| 页面层 | page.py，UI控件和交互 | React/Vue组件 |
| 公共层 | app/core/工具函数和组件 | 前端公共组件+后端工具 |

### 依赖方向
```
页面层 → 服务层 → 引擎层
   ↓       ↓
公共层 ←──────┘
```
