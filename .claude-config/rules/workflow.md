## § 1. 任务前必查(横切关注点)

### 1.1 开局体检【强制 1】
首次接触项目或切换工作目录时,扫描下表,**仅在异常时报告**。

| 检查项 | 报告条件 |
|--------|---------|
| 仓库根位置 | 仓库根 ≠ 项目目录 |
| `.gitignore` 完备性 | 缺失或漏关键类别 |
| 暂存区状态 | 含密钥 / 虚拟环境 / IDE 元数据(细则由 `git_commit_safety.sh` 兜底) |
| 工具链信号 | 任务涉及包管理时必须先识别 |
| 远程仓库 | 用户提交/推送时报告 |

**阻断**:仓库根错位且未报告 → **[阻断 1] 必须先报告异常并询问用户**。

### 1.2 工具链识别【强制 2】
任务涉及包管理(pip/uv/poetry/npm/yarn)前,必须先读 pyvenv.cfg / lock 文件识别。

**阻断**:未识别就执行包管理命令 → **[阻断 2]**。

### 1.3 不可逆操作必先问【强制 3】
横切关注点涉及不确定时,**必须先报告 + 询问**。禁止:
- "先做后说"(给用户已成事实)
- "应该没事"替代实际检查
- 把横切问题混在任务汇报里
- 自决删除 `.git/` / `.env` / 锁文件

**阻断**:未问就执行不可逆操作 → **[阻断 3] 立即停止并报告**。

### 1.4 回滚自检表【强制 4】

**触发**(任一):
- 删除文件 / 删除分支 / `git reset --hard` / force push (物理拦由 `dangerous_bash.sh` 兜底,本规则补思考层)
- 重构涉及 ≥3 个文件
- 修改公开函数签名
- 数据库 schema 变更 / 批量数据写入

**必须输出**:
```
[回滚方案自检]
- 改动类型: ____
- 当前状态保存: □ git stash □ git commit □ 备份(路径) □ 无需保存
- 回滚方式: □ git revert □ git reset --hard □ 恢复备份 □ 其他
- 回滚验证点: ____ (回滚后如何确认状态正确)
```

**阻断**:有未保存改动 / 无回滚方式 / 验证点未说明 → **[阻断 4]**。

### 1.5 测试存在则必跑【强制 5】

**触发**(任一):
- 改 `src/X.py` 且 `tests/test_X.py` 存在
- 改的函数被某测试 import

**必须输出**:
```
[测试自检]
- 修改文件: ____
- 对应测试: ____
- 运行: □ 已通过 □ 已失败(处理方式: ____) □ 未运行(阻断)
- 用例: □ 已覆盖 □ bug 修复已加复现用例 □ 行为变更已调用例 □ 纯重构无需调
```

**阻断**:测试存在未运行 / 失败未处理 / bug 修复未加用例 / 行为变更未调用例 → **[阻断 5]**。

## § 2. 任务后必报(横切关注点)

### 2.1 主动汇报"未做的事"【强制 6 — 重点保留】

**为什么是强制 6**:这是用户发现 AI 漏规则的**唯一系统性反馈机制**。AI 自评"☑全通过"不可靠,必须靠主动汇报暴露漏洞。

完成汇报除"我做了什么",**必须**列出符合下列任一的事:
- 开局体检异常(仓库根 / .gitignore / 暂存区 / 工具链)
- 上下文耦合升级为中/高风险(见 § 3.1)
- 残留未提交状态(stash / 未跟踪新文件 / 已 tracked 但未一起提交)
- 本次自我豁免的规则(走快速通道、跳了某项自检、拍脑袋的决定)

**禁止汇报**:纯审美建议、与任务无关的发现、用户已表态不关心的事。

**阻断**:命中任一却未列入 → **[阻断 6] 用户可直接打断"你没汇报 X",AI 必须立即补全**。

> **给用户**:发现 AI 漏报时直接说"你漏了 X" — 这是设计好的纠偏机制。

## § 3. 辅助约束(不算强制)

### 3.1 上下文耦合风险评估
单任务风险评级时,看当前项目状态是否会放大副作用。

| 单任务等级 | 升级触发 | 升级后等级 |
|-----------|---------|----------|
| 低 | 暂存区已混乱、用户可能随手 commit | 中 |
| 低 | 涉及 `.env` / 密钥 / 锁文件残留 | 中 |
| 中 | 改动叠加 `.git` 删除 / 分支重写 | 高 |

升级后按 `CLAUDE.md` § 1.5 处理(高等级必须用户确认)。

## § 4. 紧急通道豁免

用户显式声明"急,跳过"时:
- § 1 阻断部分豁免
- 但**降级声明 + 未识别风险清单 + 未验证假设清单**仍必须输出
- 老项目门 1(`flow_legacy_project.md`)豁免无效 — 必跑
- 救火型(`flow_emergency.md`)反向规则**不豁免**

## 附录:hook 已物理接管(本文件不复述细节)

具体 hook 注册见 `~/.claude/hooks/manifest.json`,大类如下:
- **物理拦截类**:危险命令 / commit 安全 / 跨层 import / lint / 类型检查 / 覆盖率门禁
- **语义检测类**:HTTP 漏 timeout / 改名残留 / Playwright sleep / FastAPI debug / RAG 反模式 / 时序 ML 反模式
- **提醒类**:工程缺口审计(.gitignore / 大文件 / 大函数 / 循环依赖 / 死代码)

> hook 失败时 AI 仍按本文件强制规则的思考层兜底,不依赖 hook 单点。
