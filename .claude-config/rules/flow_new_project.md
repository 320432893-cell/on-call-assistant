# 新项目流程

## 文件定位
- **按需加载**:仅当 CLAUDE.md 项目类型判定为"新项目/探索型"时读
- 本文件是**主流程骨干**,详细协议在 `risk_reasoning.md` 和 `info_guidance.md`(被本流程引用时才加载)

---

## 0. 触发条件
- 新项目 / 新模块
- 架构决策(从零设计某子系统)
- 需求边界不清的探索任务

---

## 1. 流程总图

```
1. 用户描述需求
2. AI 五层穷究(L1→L5)
3. 风险识别(走 risk_reasoning.md)
4. 置信度判定 < 100? 回 2-3 继续穷究 / = 100? 进 5
5. AI 出诊断报告 + 推荐范式 + 待验证假设
6. 用户复核 + 二次补充 → 触发 risk_reasoning.md § 7 再推理
7. 方案对比 ≥ 3 含反向(简单项目可跳)
8. 用户选
9. 架构骨架(目录 + 每文件 1 句话)
10. 写第一个最小可跑迭代 ≤ 50 行 + 范式落地注释
11. 工具链自动检查(ruff/mypy/hook)
12. 用户跑一下看输出
13. 增量循环
```

---

## 2. 五层穷究(L1-L5)

### L1 项目本质(1-2 题,业务话)
- 这件事最终在干什么?(动词 + 一句话)
- 输入是什么,输出是什么?

### L2 谁用 + 在哪跑(1-2 题)
- 谁触发?(自己 / 别人 / 定时 / 事件)
- 跑在哪?(本地 / 服务器 / 浏览器 / 容器 / GUI)
- 有人盯着吗?

### L3 信任边界(深挖,无题数限制)
**进入 risk_reasoning.md 的 A 推理树 + D 反推**。
信息缺口 → 进入 info_guidance.md 引导漏斗。
**不限题数,直到所有架构决策需要的信息全部到位**。

### L4 状态与生命周期
- 一锤子 vs 分多步?
- 步骤间保留什么?
- 跑到一半挂了怎么办?(可能在 L3 已覆盖,不重复)

### L5 失败代价
- 失败什么后果?(用户骂 / 损失钱 / 数据错 / 没影响)
- 谁先发现?多久发现?
- 错了能撤回吗?

## 3. 置信度判定

```
置信度 = (架构决策已获信息数 + 风险点已应对数) / 总项数 × 100

阈值:
< 100  → 列具体缺口,继续追问 / 走漏斗
= 100  → 进入诊断报告
```

**判定方式**:对照 risk_reasoning.md 的"终止条件三机制"逐项检查,**不允许 AI 自评"差不多"**。

## 4. 诊断报告(必须输出)

```
[项目诊断报告]

— 项目画像 —
类型:____
业务复杂度:____
环境复杂度:____
失败可见性:____
价值密度:____

— 风险重心识别(按风险大小排序) —
★★★ 高风险(必须设计)
1. ____ → 推荐范式 ____
★★ 中风险(强烈建议)
★ 低风险(看你)

— 推荐技术栈 —
(每项给"为什么是它,不是替代品")

— 我会用哪些范式(透明披露) —
- ____
- ____

— 我不会用什么 + 为什么(防过度设计) —
- 不用状态机:____ 原因
- 不用 OOP 重抽象:____ 原因

— 待验证假设清单 —
| # | 假设 | 验证方式 |

— 你需要确认的事(只列真需要的,不凑数) —
1. ____
2. ____
```

## 5. 方案对比(≥ 3 个含反向)

简单项目(单文件 / 一次性)可跳,直接进步骤 9。

**必须有 ≥ 1 个反向选项**:不做 / 复用现有 / 最简硬编码。

每个方案给:思路 / 好处 / 代价 / 适合什么场景。

---

## 6. 增量原则(步骤 10-13)

- 第一个迭代 ≤ 50 行,必须能跑(`first_iter_lines.sh` hook 在 Write 新文件时自动提醒)
- 每个迭代写完触发工具链(hook 自动)
- 用户跑一次看输出再写下一个增量
- 范式应用按 `CLAUDE.md` § 4.6 在**完成汇报段**列出"用了什么 / 刻意不用什么"

---

## 7. 紧急通道

用户显式声明"急,跳过":
- 跳到步骤 9(架构骨架)
- AI 必须输出**降级声明** + **未识别风险列表** + **未验证假设清单**
- 不是免责,是显式留痕

---

## 8. 反模式

- ❌ L3 走过场,不走 risk_reasoning.md 协议
- ❌ AI 自评"差不多"放行,不对照终止条件
- ❌ 诊断报告无"我不会用什么"
- ❌ 第一个迭代超过 50 行
- ❌ 完成汇报段不列"用了什么范式 / 不用什么"
- ❌ 用户二次补充后不回到风险识别再推理
